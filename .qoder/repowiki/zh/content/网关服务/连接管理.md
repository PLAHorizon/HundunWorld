## 连接监听与启动流程

游戏网络服务器通过TouchSocket框架实现TCP连接的监听和管理。`GameNetworkServer`类负责初始化和配置TCP服务，使用`NetworkOptions`中的`TcpPort`属性定义监听端口。

```mermaid
sequenceDiagram
participant GameNetworkServer as GameNetworkServer
participant TouchSocket as TcpService
participant Config as TouchSocketConfig
GameNetworkServer->>GameNetworkServer : StartAsync()
GameNetworkServer->>TouchSocket : new TcpService()
GameNetworkServer->>Config : 创建配置对象
Config->>Config : SetListenIPHosts(IP, Port)
Config->>Config : SetTcpDataHandlingAdapter()
Config->>Config : ConfigureContainer(Logger)
GameNetworkServer->>TouchSocket : SetupAsync(config)
GameNetworkServer->>TouchSocket : StartAsync()
TouchSocket-->>GameNetworkServer : 服务启动成功
```

## 连接事件处理机制

`GameNetworkServer`实现了完整的连接生命周期事件处理器，包括连接前验证、连接建立和断开连接处理。

### 连接前验证 (OnClientConnecting)

在客户端尝试连接时触发，可用于执行连接前的验证逻辑，如IP白名单检查：

```mermaid
flowchart TD
A[客户端连接请求] --> B{OnClientConnecting}
B --> C[记录连接日志]
C --> D{是否允许连接?}
D --> |是| E[继续连接流程]
D --> |否| F[e.IsPermitOperation = false]
F --> G[拒绝连接]
```

**Diagram sources**
- [GameNetworkServer.cs](file://Horizon.Game.Gateway/Network/GameNetworkServer.cs#L138-L159)

### 连接建立 (OnClientConnected)

当客户端成功建立连接后，创建`GameConnection`对象并添加到连接管理器：

```mermaid
sequenceDiagram
participant Client as 客户端
participant Server as GameNetworkServer
participant Manager as ConnectionManager
participant Conn as GameConnection
Client->>Server : TCP连接建立
Server->>Server : OnClientConnected
Server->>Conn : new GameConnection(client, logger)
Server->>Manager : AddConnectionAsync(gameConnection)
Manager-->>Server : 添加结果
alt 添加成功
Server-->>Client : 连接成功
else 添加失败
Server->>Client : CloseAsync("连接管理器拒绝")
end
```

## 连接超时与异常处理

系统实现了完善的连接超时处理和异常恢复策略，确保服务的稳定性和可靠性。

### 超时连接清理

连接管理器通过定时器定期检查并清理超时连接：

```mermaid
sequenceDiagram
participant Timer as 清理定时器
participant Manager as ConnectionManager
participant Conn as GameConnection
Timer->>Manager : CleanupConnections()
Manager->>Manager : 获取超时阈值
Manager->>Manager : 遍历所有连接
loop 检查每个连接
Manager->>Conn : LastActiveTime < cutoffTime?
alt 是
Conn->>Conn : CloseAsync("连接超时")
Manager->>Manager : RemoveConnectionAsync()
end
end
Manager-->>Timer : 清理完成
```
