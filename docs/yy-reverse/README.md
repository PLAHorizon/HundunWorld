# 《燕云十六声》联网玩法逆向研究报告

> 研究口径：**只取开放世界 / 联网共享内容**。主线、残章、支线、奇遇、单人解谜、单人剧情演出等纯单人内容一律不纳入本报告；仅在“单人/多人模式切换”“联网系统与单人内容的边界”这类必要处作为对照出现。
>
> 研究时间：2026-10-31。游戏版本以主视频说明为准（2026 年 3/4 月的 2.5.5A/B/C，后续版本可能有改动）。

> **第二轮复核状态（2026-10-31）**：已重跑主/次视频并完成“宏观-微观对账”。399 条时间码引用 0 条越界；修正“同游=顶级入口”为“同游=聚合页、顶级入口含闯荡”；补入海捕细则、成就列表-详情、区域完成度与支持性 UI。UI 重铸前请先读 [11-复核：宏观-微观对账](11-复核：宏观-微观对账.md) 第 7 节的准入门槛。

## 一、素材与取证方式

### 执行摘要（先看这 6 条）

1. 燕云是“单人/多人双轨世界 + 四类核心玩法（侠境/试剑/止戈/闲趣）+ 闯荡多人活动列表 + 同游聚合页”，不是传统单一大世界 MMO；我们要抄的是**活动组织与 UI**，不是双世界。
2. 10 人侠境规则非常成熟：智能助战、奖励次数共享、同阶段每周一次、每周全通额外奖励、首次解锁“独享奖励”、缺治疗职责提示——可直接做我们 `DungeonProgress` 的配置模板。
3. 路牌是投入产出比最高的异步社交：文字/配图/点赞/好人坏人/留言/花材料加固 + 分层可见性设置；我们只需一个世界留言实体 + AOI 查询 + 审核。
4. 经济靠三层闸门：按来源的周上限（通宝 220,000）、周限购（不肝商店）、赛季/战令/和鸣周上限；我们的 `CurrencyGrain` 目前只有余额。
5. 组队/帮派在服务端已有 `TeamGrain`/`GuildGrain`/`DungeonGrain`，但 `SocialHandler` 的 Team/Guild 分支是**固定成功桩**——这是最该先拆的假接线。
6. 悬赏/海捕是“犯罪记录 → 悬赏单 → 真人跨世界抓捕 → 赏金”的闭环，给 PvP 一个世界内理由；我们先做 1v1，再做海捕。

### 素材

| 编号 | 视频 | 用途 | 规模 |

| 次素材 | `BV17e6GY6EmC`《燕云十六声》全主线/残章/支线全剧情流程合集（劍訣浮雲） | 只看其中的开放世界/多人行为，不分析剧情本身 | 103 P，约 82 小时；按 20 集 × 2 个时间点抽样 |

取证流水线（可复现）：

1. `yt-dlp` 拉取分 P 元数据与 720p/1080p 视频流（无登录可到 1080p30）。
2. 主素材 25 集全量下载；按 0.5 fps 抽帧，做 32×18 灰度感知去重（阈值 5.0，每 24 秒强制保留），每集压缩为 ≤72 个代表帧。
3. 代表帧按 4×4 联系表（contact sheet）分组，每格标注片内时间码；对关键屏再按时间码回抽 1280×720 原帧（`frames_full`）。
4. 对代表帧尝试 RapidOCR（中英文）以形成“时间码 → 屏上文字”语料；本机多线程 OCR 在 8 进程下卡住，最终仅 P01 完成，其余以人工读帧 + 画面字幕为准（见“局限”）。
5. 本报告所有结论分三档标注：
   - **【实证】**：画面/OCR 直接可见（给出分 P 与时间码）。
   - **【旁证】**：官方/媒体/攻略资料与画面互相印证（给出来源）。
   - **【推断】**：从画面表现与工程经验反推，未拿到客户端/服务端证据。

## 四、主要局限

- 未对解说音轨做语音转写；解说信息通过画面底部字幕 OCR 间接获得，字幕不全处以画面为准。
- 未接触客户端/服务端二进制，技术章节除画面可证部分外均为推断。
- 视频为 2026 年 3/4 月版本；数值/上限/界面可能已随赛季变化。
- 抽帧为“代表帧”而非全帧；时间码精度约 ±2 秒。
- **时间码校正说明**：第一版联系表的时间码按“保留帧序号”推算，遇到去重跳帧会偏移；核心结论已改用按 `-ss` 回抽的原帧（`frames_full`）复核，并以 `09-逐集证据索引` 的时间为准。若正文个别旧时间码与证据图不一致，以证据图/原帧为准。
- 未能完成全量 OCR（RapidOCR 多线程在本机卡住）；仅 P01 有完整 OCR 语料，其余以人工读帧为主。这不影响画面可见的结论，但可能漏掉部分字幕信息。
