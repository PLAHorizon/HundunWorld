# 03 · 经济与养成逆向

> 口径：只分析联网/共享经济与联网养成；单人模式等级、单机剧情奖励不计入。  
> 证据：P=分 P，时间码=片内时间；【实证】画面可见，【旁证】公开资料互证，【推断】工程反推。

## 1. 货币体系：多币种 + 分区 + 周上限

### 1.1 钱袋页（P04 01:20–02:20）

「钱袋」页是目前最完整的经济证据：

- 顶部两个大类：**区域货币** / **其他货币**。
- 区域货币格：宋元通宝 49,047；另有三档大额货币（315 万 / 342 万 / 202 万）与 1,000 档；底部页签「通宝 / 宝钱 / 不肝商店 / 长鸣玉 / 其他」。
- 其他货币格：多种玉石/羽毛/材料，数量从 2 到 985,000 不等。
- 右侧详情（以宋元通宝为例）：
  - 名称：宋元通宝（五代宝钱）
  - 持有：49,047
  - 说明：宋太祖赵匡胤所铸通宝，图企图以此统一天下货币；目前在开封地区使用十分普通，未央城商人身上可能携带这种货币。
  - **日常玩法通宝：32,208 / 220,000**
  - 获取途径：代币兑换 / 不肝商店-幺玉兑换 / 不肝商店-体力兑换 / 开封区域探索
  - 获取上限（右侧浮层）：每周至多获取通宝 220,000；心力玩法、怪物击杀拾取、红宝、一次性奖励及通宝兑换**不纳入**通宝获取限制。

### 1.2 货币分层（按证据可确认）

| 层级 | 货币/材料 | 作用 | 证据 |
|---|---|---|---|
| 区域流通货币 | 宋元通宝、宝钱 | 区域商店、NPC 购买、兑换 | P04 01:20、03:06；P11 03:10 |
| 装备材料 | 振玉·朔/璃/瑶/琚、振玉 | 装备打造/培养 | P08 00:34–01:20；P11 02:30 |
| 奇术材料 | 乌金铁（一阶/二阶/三阶…） | 奇术培养/突破 | P09 00:18–01:12；P11 05:12 |
| 武学/心法材料 | 武学心得（散本/自选）、心法心得（散本/自选） | 武学/心法升级 | P10 00:38–00:44；P11 02:30 |
| 强化材料 | 磐石 | 装备强化/精炼 | P08 00:08；P11 05:04 |
| 周限购货币 | 不肝商店代币（页面内计价） | 兑换上述材料 | P11 02:30、05:12 |
| 社交周货币 | 四海笺（每周获得 0/1000） | 同游页右上进度；用途未在画面展开 | P11 01:34 |

【推断】区域货币（宋元通宝/宝钱）承担“地区经济”与“通胀控制”；材料货币承担“养成节奏”；不肝商店承担“用时间换材料”的保底；四海笺承担“每周社交/同游”的轻量目标。

### 1.3 经济闭环

```
玩法产出（副本/日常/世界事件/生活技能）
   ├─ 区域货币（宋元通宝/宝钱）──→ NPC 商店（销金窟）/ 兑换 / 交易
   ├─ 装备材料（振玉系列）──────→ 装备打造/精炼/继承
   ├─ 奇术材料（乌金铁）────────→ 奇术培养
   ├─ 武学/心法心得────────────→ 武学/心法升级
   └─ 周限购代币───────────────→ 不肝商店（材料保底）
外部注入：战令/月卡/商城/和鸣/充值（主要卖外观与便利）
```

设计要点：

1. **产出分类**：一次性奖励、心力玩法、怪物掉落不占周上限；可重复日常占上限。这样既防刷，又不惩罚探索。
2. **多入口兑换**：同一货币可由“代币兑换 / 不肝商店 / 区域探索”多路获得，降低单一路径依赖。
3. **周上限可见**：UI 直接显示“32,208 / 220,000”，玩家能预期本周还能拿多少。

## 2. 防刷与上限：三层闸门

| 闸门 | 作用 | 证据 |
|---|---|---|
| 周获取上限 | 限制可重复产出（通宝 220,000/周） | P04 02:08 |
| 周限购 | 限制材料兑换（不肝商店每格“周限购 40/40”） | P11 02:30、05:12 |
| 赛季经验上限 | 限制战令进度（本周上限 0/18,000） | P11 04:04 |
| 和鸣周上限 | 限制抽卡积分（本周上限 0/2,000） | P11 03:52 |
| 心力 | 限制副本产出频率 | 旁证：试剑/侠境消耗心力 |

### 2.1 设计要点

- **上限按“来源”而非“货币”**：通宝上限只算日常玩法，心力玩法/怪物掉落/一次性奖励不计入。这是“防肝不防玩”的关键。
- **上限值大而明确**：220,000 是“周常可刷满”的量级，不是“每天几百”的抠门限制。
- **限购与上限分离**：不肝商店用“周限购”控制材料投放，货币上限控制通胀，二者不混用。

### 2.2 对我们的映射

- 我们 `CurrencyGrain` 目前更像“余额账本”，缺少“按来源分类的周期上限”。
- 建议新增 `CurrencyCapRule`（货币、来源类别、周期、上限、是否计入），在发奖入口统一校验；回执带 `granted / used / cap` 三元组。
- 客户端钱袋页/商店页直接显示三元组，避免玩家“为什么打了不涨”的困惑。

## 3. 养成四轴：角色 / 武学 / 心法 / 奇术 / 装备

P08 00:02、P09 00:02、P10 00:02、P07 00:02 的「培养」轮盘把养成拆成五块：

> 角色 · 武学 · 心法 · 奇术 · 装备

### 3.1 角色（P07）

- 角色等级/天赋树：P07 00:12 显示等级 21、天赋点 100/100、125/85、600 等；
- 属性加成：气血上限 +20.7%、移速 +22.3%、气血恢复 +7.2%、全部属性 +192/+208；
- 突破奖励：二阶·燕山 / 三阶·观海 / 四阶·浮岸 / 五阶·梦浮 / 六阶·洞明；
- 战斗难度：辅助 / 简单 / 普通 / 困难 / 噩梦（P07 00:32）。

注意：其中的「单人模式等级」属于单人内容，本文只把它当作“双轨数值隔离”的证据，不展开。

### 3.2 武学（P06）

- 页签「功法 / 装备 / 天赋」；
- 主武学 + 副武学 + 招式/连招；
- 「武学推荐」四类定位：输出近战 / 输出远程 / 承伤近战 / 治疗远程（P06 00:20–00:34）；
- 每个定位给主武学/副武学/心法/奇术的搭配方案，可一键应用；
- 武学有等级（100/100）、招式等级（1级、30级等）、突破/进阶；
- 资源：耐力（武学蓝量）、精元（奇术蓝量）——旁证术语表。

### 3.3 心法（P10）

- 心法槽位（页面显示 6 个槽）；
- 心法详情 / 心法置装 / 心法转换 三个页签；
- 心法心得（散本/自选）用于升级；
- 心法效果示例「易水歌」：每次攻击或治疗有 60% 概率叠加 1 层，每层提升 2% 伤害/治疗，最多 5 层；持续 6 秒；对精英/首领生效（P10 00:12、05:34）。
- 心法可转换，降低“练错”成本。

### 3.4 奇术（P09）

- 4 个奇术槽；
- 五行标签（金/木/水/火/土）；
- 奇术示例：金玉手、凌虚一指、回风照影、太极等；
- 奇术有等级/突破（6重 15/15）；
- 材料乌金铁按阶（一阶/二阶/三阶…）；
- 不肝商店可换乌金铁（周限购）。

### 3.5 装备（P08、P22）

- 10 个装备位（头/胸/腰/腿/手/足/武器/暗器/戒指/项链等，画面可见 10 格）；
- 装等（1154/1177）、等级（100级）、品质（金/紫等）；
- 基础词条 + 附加词条：外功攻击、属性攻击、精准、会心、会意、气血、防御等；
- 套装 4/4 与套装效果；
- 强化/精炼/继承/洗练（培养轮盘：装备品阶/装备打造/装备精炼/装备继承/装备洗练/装备…）；
- 装备评分（P08 00:16 显示 105 装等、装备评分；P07 01:04 装备追伤）；
- 背包页签「装备 / 道具 / 任务」；筛选维度：等级、品质、部位、套装、词条类型（P22 00:08–00:30）；
- 装备对比：两把武器并排（976 vs 432），逐条差值高亮（P22 00:38）。

### 3.6 养成循环

```
副本/世界事件 → 装备 + 材料 + 货币
      ↓
装备打造/精炼/词条 → 战力提升 → 更高难度副本/团本
      ↓
武学/心法/奇术 → 角色定位与手感 → 组队职责
      ↓
不肝商店/周上限 → 保底与防刷
```

设计要点：

1. **多轴但收敛到“战力”**：装备、武学、心法、奇术都能提升战斗，但定位由武学+心法+奇术决定。
2. **定位先于职业**：推荐的是“输出近战/远程/承伤/治疗”，不是锁死门派。
3. **降低练错成本**：心法可转换、装备可继承，鼓励尝试。
4. **词条深度**：装备有随机词条与套装，提供长期刷取目标；但核心词条（精准/会心/会意）有上限，避免无限膨胀。

## 5. 商业化与公平性

### 5.1 可见的商业化入口

- 商城八页签：推荐 / 外观 / 精选 / 月卡 / 和鸣 / 福利 / 交易 / 充值（P04 03:26）。
- 战令/月卡：每日/每周/赛季任务（P11 04:04）。
- 和鸣：限定池、等级、经验、周上限（P11 03:40–03:52）。
- 外观：时装/坐骑/宠物（P11 02:54–03:00）。

### 5.2 公平性设计

- 【旁证】TapTap 长评与攻略普遍称“氪金不碰战斗数值”“武学靠探索/偷师/奇遇/剧情解锁”；商城主要卖外观/月卡/战令。
- 战斗材料主要来自玩法（副本/世界事件/生活技能），不肝商店提供保底兑换。
- 【推断】和鸣更偏“外观/收集”而非战斗数值；若要借鉴，必须严格限制为外观，避免破坏我们服务器的数值公平。

### 6.1 建议的优先级

1. **P0：货币周上限 + 不肝商店**（服务端规则 + UI 三元组）——直接决定经济是否会被刷穿。
2. **P0：装备/武学/心法/奇术四轴的材料与槽位**——决定副本奖励是否有意义。
3. **P1：NPC 商店（销金窟）+ 玩家交易（MarketGrain）**——决定世界经济的活性。
4. **P1：战令/赛季**——决定周常/赛季留存。
5. **P2：和鸣/外观商城**——商业化，最后做，且只做外观。

## 7. 设计原则总结

1. **多币种、分区、分层**：区域货币管地区，材料管养成，周限购管保底。
2. **上限按来源分类**：一次性/心力/掉落不计入，日常可重复计入。
3. **不肝商店是“时间保底”**：让非酋/休闲玩家也能稳定获得材料。
4. **养成多轴但收敛到战力**：装备/武学/心法/奇术都能提升，但定位由武学+心法+奇术决定。
5. **降低练错成本**：心法转换、装备继承、词条筛选。
6. **外观与战力分离**：商城主要卖外观/便利，战斗材料靠玩法。
7. **所有数字都要可见**：持有/本周已用/上限/剩余库存/售罄，减少玩家猜疑。
