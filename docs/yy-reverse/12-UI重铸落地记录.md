## 2. 设计取舍

- **不写假数字**：四海笺/心力/本周目标均显示 `—`，并标“未接入”；不把视频里的 447/600、0/1000 当成我们游戏的数据。
- **不做假交互**：闯荡 8 项、挑战 2 项的行动按钮为“未接入”且禁用；侠境/试剑/止戈/闲趣只做**真实路由**（到现有副本/多人/休闲页）。
- **入口即信息**：侠境 10人、试剑 5人、止戈 PvP、闲趣休闲、闯荡多人，徽标直接上卡；状态行写“待接入”而不是假装有奖励。
- **响应式**：页面按 1920×1080 设计，`ApplyLayout` 用实际 `Width/Height` 重算；卡片内部在 `OnSizeChanged` 排布，避免构造期尺寸为 0 的叠字。
- **可复用**：`InkBadge`/`InkStatCell`/`InkActivityCard` 不依赖活动页，可给后续地图/组队/成就页复用。
- **多人地图层只认真实数据**：玩家点来自 `SelectableEntityTag.Active`（远端实体注册表，过滤 `Player`、排除本地、限定当前世界场景），队友判定用 `TeamClientService` 回执里的角色 ID；位置经 `PluginNavigationBridge` 投影。没有远端玩家就不画点，并提示「附近暂无其他玩家」。
