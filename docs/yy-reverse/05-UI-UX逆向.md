# 05 · UI / UX 逆向：墨色信息建筑

> 口径：只分析联网相关界面（活动、组队、副本、地图、背包、商店、路牌、悬赏、设置）；单人剧情/对话选项只在对 UI 模式有借鉴意义时出现。  
> 证据：P=分 P，时间码=片内时间；【实证】画面可见，【旁证】公开资料互证，【推断】工程反推。

## 1. 视觉语言

### 1.1 色彩（从关键帧采样）

对 P04（货币/商店）、P11（侠境）、P24（地图）、P22（背包）的关键帧做 10 色量化，主色集中在：

| 色值 | 占比 | 用途（推断） |
|---|---|---|
| #1D1D1E / #191919 / #222527 | 10–14% | 面板底/遮罩，近黑墨色 |
| #4E4F56 / #524C46 / #393C3E | 10–15% | 次级面板/岩石/场景 |
| #C1C1BF / #DADAD7 / #E2E0E6 | 8–12% | 宣纸白文字/高光 |
| #878789 / #A1A6B0 | 10% | 次级文字/图标 |
| 金色/朱红 | 少量 | 强调、品质、危险、按钮 |

结论：**低饱和墨灰 + 宣纸白 + 少量金/朱红**。不是高饱和国风，而是“水墨+金属”的克制配色。

### 1.2 材质与形状

- 面板：半透明深墨底 + 细金线/细白线描边，圆角很小或直角；
- 背景：宣纸纹理/山水晕染/雾气；地图为纸面 + 墨线；
- 图标：线描+少量填色，圆形/菱形/印章形；
- 字体：宋体/楷体倾向，标题大字，正文小字；数字用等宽/表格式排布；
- 强调：金色描边、朱红印章、竖排标签。

### 1.3 对我们的映射

- 我们 Ink 主题已有水墨/宣纸 token（`StyleSystem/InkWashTheme.cs`、`UIStyleTokens.cs`、`InkBackgrounds.cs`）。
- 可借鉴的增量：
  1. 统一“近黑面板 + 0.45–0.55 透明度 + 1px 金线”的容器规范（我们已有 0.45 墨底，见项目记忆 HUD overlay）；
  2. 品质色/危险色只用于小面积（图标、描边、印章），不要整块高饱和；
  3. 数字用表格/等宽对齐（货币、属性、伤害）；
  4. 标题用大字+留白，正文控制在 10–12px（1920×1080 设计空间），并做换行/截断规范。

## 2. HUD 布局（联网场景）

### 2.1 全局安全区

以 P03/P24 的 1280×720 画面归一化到 1920×1080：

| 区域 | 内容 | 安全边距（约） |
|---|---|---|
| 左上 | 小地图（圆形）+ 罗盘条 + 任务追踪 | 24–32px |
| 上中 | Boss 血条/名称/计时；无 Boss 时为罗盘/目标 | 24px |
| 右上 | 系统入口一排图标 | 24px |
| 左下 | 聊天/状态/队伍 | 24px |
| 下中 | 玩家气血/真气 | 24–40px |
| 右下 | 技能轮盘 + 交互提示 | 24px |

### 2.2 分层原则

1. **常驻层**：小地图、任务、血条、技能轮盘——始终可见。
2. **上下文层**：Boss 条、目标锁定、交互提示、悬赏状态——按需出现。
3. **瞬时层**：伤害数字、拾取提示、系统 toast——短时出现，不遮挡常驻层。
4. **菜单层**：打开菜单时压暗世界，但 HUD 仍可保留关键状态（血量/队伍）。

### 2.3 与我们的差距

- 我们已有 HUD 两套（传统/V2），但 Boss 条、目标锁定、伤害数字分层、悬赏状态缺失。
- 建议先做“常驻层/上下文层/瞬时层”三层容器，再逐项填内容；避免把新元素直接塞进页面根节点导致重叠（项目记忆有多起 (0,0) 叠字案例）。

## 3. 菜单信息架构

### 3.1 一级入口

P11 01:42 的顶部导航：**侠境 / 试剑 / 止戈 / 闯荡 / 闲趣**；P11 01:34 的「同游」页是四卡聚合页（侠境/试剑/止戈/闲趣）。  
P04/P11 的商城：**推荐 / 外观 / 精选 / 月卡 / 和鸣 / 福利 / 交易 / 充值**。  
P24 的地图：**地图 / 探索 / 挑战** + **单人 / 多人** + 图层（一层/二层/三层）。  
P22 的背包：**装备 / 道具 / 任务**。  
P08/P09/P10 的培养：**角色 / 武学 / 心法 / 奇术 / 装备**。

规律：

- **一级不超过 8 个**；超过则分组（同游聚合、商城分页）。
- **左侧竖排/顶部横排页签**二选一，不混用。
- **页签内再分“列表/详情”**，详情固定在右侧。

### 3.2 典型页面模式

| 模式 | 页面 | 结构 | 证据 |
|---|---|---|---|
| 列表-详情 | 钱袋、装备、心法、奇术、商店 | 左列表/网格 + 右详情 | P04 01:20；P08 02:10；P22 00:38 |
| 卡片墙 | 同游、侠境、闲趣、商城 | 2–4 列卡片，带角标/进度 | P11 01:42、04:24 |
| 轮盘/环 | 培养（角色/武学/心法/奇术/装备） | 中心人物/图标 + 环形节点 | P07 00:02；P08 00:02；P10 00:02 |
| 全屏地图 | 世界地图 | 纸面地图 + 侧栏区域进度 + 图层 | P24 00:02–00:48 |
| 任务日志 | 武林录/任务 | 左分类 + 中列表 + 右详情 | P14 00:02 |
| 设置 | 路牌/战斗难度 | 左分类 + 右表单 | P12 00:30；P07 00:32 |

### 3.3 关键交互细节

- **右侧详情固定**：钱袋/装备/心法/商店都采用“左选右看”，减少页面跳转。
- **角标/徽标**：10人、周限购、本周、剩余、品质、职业定位，都做成小徽标（P11 01:42、P11 02:28）。
- **进度可见**：装备 4/4 套装、心法 5 层、赛季 3614/5000、周上限 32,208/220,000。
- **分类筛选**：背包有等级/品质/部位/套装/词条类型五维筛选（P22 00:30）；地图有区域/图层/任务筛选。
- **对比**：装备并排对比，差值高亮（P22 00:38）。
- **空态**：无数据时给“未接入/暂无”而不是假数据（P11 的周限购“剩余库存 0”；我们项目也采用此原则）。

## 4. 逐屏拆解（联网相关）

### 4.1 钱袋（P04 01:20–02:20）

布局：

```
[钱袋]                                   [搜索] [货币类别]
[区域货币] 5 格大图标 + 数量
[其他货币] 12 格小图标 + 数量
[底部页签] 通宝 / 宝钱 / 不肝商店 / 长鸣玉 / 其他
                        右侧详情：名称/品质/持有/说明
                                  获取途径（可展开）
                                  获取上限（浮层说明）
```

优点：货币分类清楚、获取途径可展开、上限解释放在详情而非弹窗。  
可借鉴：我们的商店/背包应同样提供“获取途径 + 上限”说明，而不是只显示余额。

### 4.2 同游（P11 04:24）

布局：2×2 大卡（本周快活通关奖励 / 本周多态奖励 / 帮派战 / 修我戈矛），卡片带 Boss 立绘、10人徽标、奖励图标。  
优点：一屏回答“本周打什么、几人、给什么”。  
可借鉴：我们 `MenuActivitiesPage` 可改成“本周目标卡 + 内容入口卡”，而不是系统列表。

### 4.3 侠境 Boss 卡（P11 01:42）

布局：左 Boss 立绘/场景，右侧信息（推荐武学/挑战模式/本周首领/本周奖励/专属外观/挑战次数/队伍），底部「开始匹配 Space」。  
优点：Boss 即入口，信息密度高但不乱。  
可借鉴：我们副本页可用“Boss 立绘 + 三个关键标签 + 一个主按钮”，不要堆文字。

### 4.4 地图（P24 00:02–00:48）

布局：

```
[单人/多人] [地图/探索/挑战] [搜索]
[左：图层 一层/二层/三层] [中：纸面地图+POI] [右：区域进度/本周目标]
[底部：药匣可升级 / 本周流派试炼 剩余27天]
```

优点：地图不是“全屏一张图”，而是“地图 + 目标 + 进度”的工作台。  
可借鉴：我们 `WorldMapPage`/`CompassPage` 已有 POI/坐标，可增加“区域完成度 + 本周目标 + 图层”。

### 4.5 背包/装备（P22 00:08–00:54）

布局：顶部页签 装备/道具/任务；左装备槽 10 格；中物品网格；右详情（名称/等级/品质/属性/词条/套装）；筛选在右上。  
优点：装备槽与背包同屏，减少“穿装备要跳页”；对比直接并排。  
可借鉴：我们 `MenuEquipmentPage` 已接真实快照，可增加“并排对比 + 词条筛选 + 套装 4/4 进度”。

### 4.6 不肝商店（P11 02:30、05:12）

布局：左侧分类（装备宝匣/全意货币/营生货币），中间商品网格，每格下方“周限购 40/40”和价格，右侧详情（名称/用途/获取途径/限购）。  
优点：限购与价格同屏，玩家不用点详情就知道能不能买。  
可借鉴：我们商店页应把“周限购/剩余/价格”做成卡片元数据，而不是藏在 tooltip。

### 4.7 路牌设置（P12 00:30–00:38）

布局：设置页左分类 + 右表单，多个开关：

- 自己放置的路牌显示（显示/关闭）
- 其他玩家放置的路牌显示（关闭/开启）
- 江湖人士放置的路牌显示（关闭/开启）
- 是否自动加入帮派路牌（关闭/开启）
- 是否记录重伤信息（关闭/开启）
- 路牌公开显示（显示/隐藏）
- 路牌音乐盒设置
- 仅显示好友/帮派路牌

优点：把 UGC 的可见性做成玩家开关，兼顾社交与隐私。  
可借鉴：这是最值得抄的“设置粒度”。

### 4.8 悬赏（P18 02:32–03:46）

布局：律令页（犯罪记录）+ 江湖悬赏页（悬赏设置/金额/公示/刷新）；世界 HUD 左上红色悬赏状态。  
优点：把“玩家犯罪”做成可查询、可挂赏、可追捕的闭环。  
可借鉴：我们若做 PvP，必须先把“犯罪记录/悬赏状态”做成服务端状态，而不是 UI 假数据。

### 4.9 成就/收集：列表-详情 + 分类计数（P23 00:56）

- 左栏按「区域 / 武林纪事 / 红尘闲游 / 刀光剑影」分组，每组显示 `55/61`、`31/34` 等完成计数；
- 中栏是成就列表：图标、名称、描述、奖励、勾选状态；
- 右侧/底部：「筛选」「一键领取」「达成」；
- P23 00:08–00:52 还展示了「森罗万象」隐藏成就、筛选面板（类型/难度/奖励状态/完成状态）与「查看其他玩家留言」。

这是典型的 **三段式列表-详情 + 筛选 + 批量领取**，可直接复用到我们的成就/图鉴/任务日志。注意：P23 的具体成就内容属于单人收集，不纳入联网玩法结论，只取 UI 结构。

### 4.10 区域完成度：收集工作台（P25 02:56）

- 顶部页签：镇守 / 侠迹 / 明暗故事 / 众生 / 万事知 / 据点，每项 `100%`；
- 下方按区域（百草野 / 隐月山）排地点卡，每张卡显示地点名与 `100%`；
- 底部：「地区：清河」「发布悬赏」「说明」。

这证明“地图/武林录”不是一张静态图，而是**区域完成度 + 分类进度 + 地点卡**的工作台。我们做 UI 重铸时，应把 `WorldMapPage`/`CompassPage` 的右栏从“信息展示”升级为“区域进度 + 分类筛选 + 地点卡片”。

### 4.11 支持性 UI（P25 01:18–02:38）

- 场景回溯/任务回顾（01:18、01:22、02:00）；
- 键位设置与「逃离卡死」选项（02:24–02:26）；
- 退出重进/重连（02:30–02:38）。

这些是“出问题时可自救”的界面，建议在我们 UI 重铸时保留/补齐：卡死逃生、场景回溯、重连状态。

### 5.2 字号/间距

- 1920×1080 设计空间：标题 28–36px，页签 18–20px，正文 12–14px，辅助 10–12px，数字 14–18px 等宽。
- 行高 1.4–1.6；卡片内边距 16–20px；页面边距 32–48px。
- 右侧详情固定宽度 360–420px；左侧列表 520–640px；中间网格自适应。

### 5.3 组件清单（建议补到 Ink 组件库）

- `CurrencyCell`（图标/数量/上限/获取途径）

- `RoleTag`（输出近战/远程/承伤/治疗）
- `BossCard`（立绘+标签+主按钮）
- `ProgressWheel`（培养轮盘）
- `RegionProgress`（区域 100%/本周目标）
- `ComparePanel`（装备并排差值）
- `RoadSignSettings`（可见性开关组）
- `BountyStatus`（悬赏 HUD 状态）

### 5.4 交互规范

- 键鼠 + 手柄双输入：所有提示同时支持 `F/E/LB/LT` 与鼠标点击；
- 页签切换用左/右键或 Q/E；
- 列表项 hover 显示详情预览，点击固定右侧详情；
- 重要操作（购买/进入副本/解散队伍）二次确认；
- 空态/未接入状态必须明确，不能用假数据；
- 所有“周上限/剩余次数/限购”必须可见。

## 6. 优点与问题（批判性）

### 6.1 优点

1. **信息建筑克制**：一级入口少，详情右侧固定，减少跳转。
2. **每个数字都有上下文**：上限、限购、本周、剩余、品质、人数。
3. **地图是工作台**：不是装饰，而是任务/进度/POI 的入口。
4. **UGC 治理前置**：路牌可见性做成设置，而不是事后审核。
5. **视觉统一**：墨色/宣纸/金线，低饱和，长时间看不累。

### 6.2 问题

1. **信息密度高**：720p 下大量 10–12px 文字，电视/小屏可读性差。
2. **层级深**：同游→侠境→Boss→详情→入口，至少 4 层；新手容易迷路。
3. **术语多**：侠境/试剑/止戈/闯荡/闲趣/百业，需要学习成本。
4. **颜色对比不足**：深色面板 + 灰字，弱视/强光下可读性风险。
5. **伪 3D 转场多**：卡面立绘/轮盘动画可能拖慢低端设备（推断）。

### 6.3 对我们的启示

- 保留“少入口、右详情、数字带上下文”的优点；
- 改善“深层级”：用面包屑/返回栈/最近访问；
- 提高对比度：主文字至少 #E8E6E1，正文不小于 12px@1080p；
- 术语表/首次引导：在活动中心加“一句话解释”；
- 动效降级：低端设备关闭轮盘/粒子动画。
