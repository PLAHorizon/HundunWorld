## 1. 同游：四卡聚合页与“今天玩什么”

### 1.1 画面与信息结构（P11 01:34）

- 右上：「四海笺每周获得 0/1000」。
- 四张大卡：
  - **侠境**：轮战首领，绝地反击；「本周侠境通关奖励」。
  - **试剑**：力挫首领，横扫据点；「奖励已领取」。
  - **止戈**：修我戈矛·一重境；赴赴群侠，以武会友。
  - **闲趣**：民俗赓戏，浮生偷闲。
- 底部：「H 发布悬赏」「返回」。
- 顶部导航：同游 / 商店（这是从某个入口进入的独立页；活动页的顶部导航是侠境/试剑/止戈/闯荡/闲趣）。

### 1.2 设计要点

1. **同游是“四卡聚合 + 每周目标”**：把四类玩法放在一页，右上给周货币进度（四海笺 0/1000），减少入口层级。
2. **每卡都有副标题/状态**：侠境“本周通关奖励”、试剑“奖励已领取”、止戈“一重境”、闲趣“民俗赓戏”——入口即状态。
3. **发布悬赏在底部**：把 UGC/悬赏入口放在聚合页，而不是藏进社交菜单。

### 1.3 对我们的映射

- 客户端已有 `MenuActivitiesPage`、`MultiplayerPage`、`MenuTeamPage`、`DungeonEntryPage`，但均为设计稿/未接服务端（`MultiplayerPage.cs:461` “大厅服务尚未开放”，`MenuTeamPage.cs:410` “组队功能未接入”，`DungeonEntryPage.cs:472` “秘境副本尚未接入”）。

## 2. 侠境：10 人团本与周本

### 2.1 画面证据

- P11 01:34「同游」页：本赛季 2026-03-27 ~ 2026-05-08、本周快活通关奖励、本周多态奖励、帮派战入口。
- P11 01:42：侠境页「夹钟奏雅·上」，三个副本/挑战路线「离思赋 / 潇翰 / 鲲鹏图千山」；Boss 立绘「白裘殁天狼」右上角「10人」；规则文案见 2.3。
- P11 02:06：Boss 卡片「白裘殁天狼」，10人、智能助战/团队、推荐武学造诣 40120/38000、本周首领奖励、专属外观、缺少治疗职责。
- P11 01:34 的同游页四卡分别给出侠境/试剑/止戈/闲趣的副标题与状态；规模徽标在侠境详情页（01:42/02:06）。
- P16 04:12–05:44：武林录的「据点 / 野外首领」分类页（这两类是**收集/挑战分类**，本视频未证明其必须多人；见第 7 节）。

### 2.2 设计要点

1. **规模与门槛清晰**：10 人、51 级解锁（旁证）、周本、每周奖励次数。
2. **“本周首领”轮换**：同一副本按周轮换 Boss/词条，延长内容寿命。
3. **“协助清剿”**：允许助战/补位，解决 10 人本组队难。
4. **奖励分层**：通关奖励、本周奖励、专属外观、赛季奖励，分别服务“首通/周常/收集/赛季目标”。
5. **Boss 立绘即入口**：卡片用 Boss 立绘而非文字列表，降低认知成本。

### 2.3 规则文本（画面实证，P11 01:42–02:06）

「夹钟奏雅·上」侠境页右侧规则面板可直接读出：

- **挑战方式**：组队挑战，队伍要求 10 人，依次挑战首领获得对应奖励！**智能助战会自动补充智能队友**，团队挑战需要少侠寻找其他游侠一起挑战。
- **奖励说明**：侠境不同难度**奖励次数共享**；同阶段每个首领**只能领取一次奖励**；组队模式可获得更好的奖励；**每周击败任一难度侠境所有首领，可在同游界面领取额外奖励**。
- **其他说明**：任意侠境副本解锁时，首次可领取的奖励为**独享奖励**，不计入周期奖励次数共享；同一副本当周无法领取两次奖励；独享奖励的副本有**特殊金线标识**提示；云梦金明池·极将根据游侠的**单人模式等级**掉落对应 56 阶或 61 阶奖励。
- **队伍状态**：右侧队伍栏显示「缺少治疗职责」，底部「开始匹配 Space」。
- **门槛**：推荐武学造诣 40120 / 38000（P11 01:26）。

这套规则回答了四个关键问题：**多少人、能不能带 AI、奖励怎么算、缺什么职责**。特别是“智能助战”与“奖励次数共享/独享奖励”的组合，兼顾了组队难与重复刷。

### 2.4 对我们的映射

- `Horizon.Orleans.Grains/DungeonGrain.cs` 已有 CreateDungeon / Players / Bosses 数据结构；`TeamGrain.EnterDungeonAsTeamAsync` 已能把队伍带进副本。
- 缺：副本模板配置、Boss 阶段/词条、周首通记录、协助/补位、匹配队列、结算发奖。
- 建议先把 `DungeonGrain` 的模板/难度/人数上限做成配置表，再接 `TeamGrain` 与网关。

## 3. 试剑：5 人本与周首通

### 3.0 挑战页与心力（P11 00:12）

「挑战」页是侠境/试剑的共同前置：

- 页签「探索 / 挑战」；标题「挑战——使用心力获取奖励，提升战斗实力」。
- 左侧两张大卡：**镇守·挑战**（指定套装、武学心得）、**据点·挑战**（随机套装、奇术碎片）。
- 右侧「玩法推荐」：**单人 → 武林录**、**多人 → 同游**——把“单人内容”和“联网内容”明确分流。
- 「心力获取」：下一点恢复 00:05:15、全部恢复 20:21:15、快速补充、自然恢复、当前心力 **447/600**。
- 底部导航：心力、试剑、侠境 / 日常周常 / 赛季。

这说明心力是**跨副本的统一入场资源**（不是每个副本各自计数），且恢复速度以“下一点/全部”两个时间呈现。

### 3.1 证据与旁证

- P11 01:34 同游页出现「试剑」入口；P06 00:20 的「推荐武学」页把队伍定位分为输出近战/输出远程/承伤近战/治疗远程。
- 旁证（17173/九游/攻略）：试剑为 5 人本，每周首通额外奖励、金色装备爆率更高；消耗心力；进入副本后仍可匹配；可按首领阶段设置匹配起点。

### 3.2 设计要点

- **5 人 vs 10 人**形成难度/社交梯度：5 人适合固定小队，10 人适合帮派/大团。
- **首通奖励**驱动每周至少打一次，避免“只刷最高效率本”。
- **心力**是软性防沉迷/防刷资源，可积累、可消耗。

### 3.3 对我们的映射

- 我们的 `DungeonGrain` 支持 maxPlayers，可直接配置 5/10 人。
- 缺“心力”资源与周首通记录；建议在 `CharacterGrain` 增加 `Stamina`/`WeeklyFirstClear` 字段，或独立的 `ActivityCapsGrain`。

## 4. 止戈：PvP 与赛季

### 4.1 画面证据

- P11 01:42 顶部一级导航「侠境 / 试剑 / 止戈 / 闯荡 / 闲趣」：止戈是与侠境/试剑并列的 PvP 入口。
- 【旁证】止戈为 PvP 总称，含论剑（1v1）、觉障林（吃鸡）、争锋、演武、天下争鸣；准备阶段禁用技能/奇术、射箭初始精元 40%、战斗中精元恢复 +20%；天下争鸣准备场景可切换武学，治疗职责不超过 1 人（17173/九游 1.5 版本公告、攻略站）。
- 【旁证】止戈有赛季积分分档与奖励（攻略站提到“低段位 PVP”“段位”）；本次视频未打开止戈详情页，故不引用具体积分截图。
- 注意：P11 02:22 的「心安鲤得·五重境 / 3614/5000/10000/15000/20000」是**不肝/赛季成长页**，不是止戈页；不要把它当成 PvP 积分证据。

### 4.2 设计要点

1. **多模式覆盖不同人群**：1v1 硬核、吃鸡低门槛、多队阵营战。
2. **准备阶段规则**：把“配装/切武学”与“开打”分离，防止开局偷跑。
3. **赛季积分分段**：每档给奖励，避免“只有顶分段有收益”。
4. **职责约束**：治疗职责上限 1，防止阵营战变成“奶妈大战”。

### 4.3 对我们的映射

- 我们目前没有 PvP 场景/匹配/赛季；`Arena` 目录存在（`Horizon.Game.Core/Handlers/Arena`、`Horizon.Orleans.Grains/Arena`），需核实完成度。
- 建议先做 1v1 论剑（复用 CombatGrain + 房间），再做吃鸡/阵营战；不要一上来做大地图 PvP。

## 5. 闲趣：休闲小游戏与社交

### 5.1 画面证据

- P11 04:16–04:20：卡面「浮景行舟」（每周四次奖励）、「烟花晚会」（当天 20:25 开启）等；同游页的闲趣卡副标题为「民俗赓戏，浮生偷闲」。
- 旁证：1.5 版本优化雀神争霸匹配落座、离桌后可邀请；射覆多次未猜中给关键提示；另有相扑/蹴鞠/斗鸡/影戏等小游戏。

### 5.2 设计要点

- **低门槛社交**：不需要战力，适合拉新/回流/情侣/帮派团建。
- **独立匹配与房间**：与战斗副本共用组队/匹配基础设施，但规则独立。
- **轻量奖励**：通常给休闲货币/外观/周常积分，不影响战斗数值。

### 5.3 对我们的映射

- 我们已有 `MenuCasualModePage`、`MiniGameCompletePage`，但无服务端小游戏逻辑。
- 建议先做 1 个“可联机的小游戏”（如棋/牌/投壶），复用 TeamGrain 房间与 Chat，验证“非战斗联机”链路。

## 6. 百业：帮派与帮会团本

### 6.1 证据与旁证

- P11 04:10 闯荡页「群力共伐」：标签「多人」、每周剩余奖励次数 2/2；文案“万人离心，不如百人同力；千人逆战，不如十人俱至。神秘首领现已现身，亟需江湖众人齐心协力，共伐强敌！”（它更像“群体活动”，是否等于帮派活动需后续验证）
- 旁证：百业=帮派；百业侠境为公会福利团本，给百业礼盒、百业声望、专属侠名；百业建造/百业战/百业商店。

### 6.2 设计要点

- **帮派团本独立于公共团本**：奖励偏帮派货币/声望，避免冲击公共经济。
- **帮派建造**：长期目标，给帮派成员共同投入的理由。
- **帮派战**：赛季/周常对抗，提供大规模 PvP 目标。

### 6.3 对我们的映射

- 服务端已有 `GuildGrain`（创建/申请/审批/踢人/职位/成员），客户端 `MenuSectPage`/`SocialGuildPage` 仍是设计稿。
- 建议先接 GuildGrain（创建/加入/成员列表/职位），再做百业团本/建造/战；不要先做帮派战。

## 7. 据点与野外首领：证据边界（先标“待验证”）

### 7.1 画面证据

- P11 01:42 侠境/挑战页出现「镇守·挑战」「据点·挑战」入口；P11 01:42 的侠境卡片有「大宋除魔」「协助清剿」「据点·挑战」等入口。
- P16 04:12–05:44：武林录底部页签「见闻 / 寻风使 / 万事知 / 据点 / 野外首领」，其中「据点」「野外首领」是**收集/挑战分类页**（显示 0% 进度、宝箱/奖励、地图标记），并非已证实必须多人的副本。
- P24 地图侧栏出现「本期流派试炼 剩余27天」「药匣可升级」等世界目标。

### 7.2 结论（保守）

- **能确认的**：游戏世界里有“据点/野外首领”这类开放世界节点，地图/武林录可追踪，且有挑战入口。
- **不能确认的**：它们是否必须多人、是否有共享血量/贡献排名、是否属于“联网共享事件”。本视频没有给出 10 人同屏打野外首领的画面。
- 因此本报告把它们列为 **P1 可选借鉴**：设计上值得做，但不要声称“燕云已验证”。

### 7.3 对我们的映射

- 我们有 `MonsterEditor`、`NpcEditor`、`MonsterAiCore`、`WorldSelectionService`、`NavigationBridge`，适合做野外首领/据点。
- 若做，缺：世界事件调度、共享血量/伤害归属、周奖励、据点进度同步。
- 建议新增 `WorldEventGrain`（事件状态/参与者/贡献/结算），客户端在地图/司南上显示事件标记；先做“单人可打、多人可协作”的宽松模式，再决定是否强制组队。

## 8. 路牌：异步社交 UGC（最值得借鉴）

### 8.1 画面证据

- P12 00:00–00:20：世界路边出现半透明“路牌”标记，靠近显示「路牌」；玩家可放置/查看。
- P12 00:10–00:20 的路牌详情面板（右侧）可见：作者名片/剩余时间、正文（“各位少侠新年快乐！！可以给我点个赞嘛 门派任务(´▽`ʃ♡ƪ)”）、配图、点赞数 753、**「好人 / 加固 / 坏人」**三个评价/互动按钮、「留言(8)」与热门评论、底部「R 联机匹配」「F 重播动作」「Enter 留言」；字幕同时说明“说他是好人，或者花点材料给他加固”。
- P12 00:30–00:38：设置页「路牌设置」：
  - 自己放置的路牌显示：显示/关闭
  - 其他玩家放置的路牌显示：显示/关闭
  - 江湖人士放置的路牌显示：显示/关闭
  - 是否自动加入帮派路牌：关闭/开启
  - 是否记录重伤信息：关闭/开启
  - 路牌公开显示：显示/隐藏
  - 仅显示好友/帮派路牌？
  - 路牌音乐盒设置
  - 江湖人士放置的路牌显示（开关）
  - 非好友/帮派路牌？
- 旁证：路牌可留言、可放音乐盒、可在死亡地点留信息。

### 8.2 设计要点

1. **低成本、高在场感**：不需要实时同屏，就能让世界“有别人”。
2. **分层可见性**：自己/好友/帮派/所有人/江湖人士，分别可控；解决骚扰与隐私。
3. **内容形态**：文字、配图、动作、评论、点赞/点踩（好人/坏人），以及“花材料加固”的轻量养成；不是单纯弹幕。
4. **设置即治理**：把可见性做成玩家开关，而不是全靠审核。
5. **社交反馈闭环**：作者得到赞/评论/加固，读者得到信息/乐子；加固消耗材料，形成“世界共建”的轻量 sink。

### 8.3 对我们的映射

- 这是**投入产出比最高的借鉴项**：我们已有聊天、世界坐标、POI、数据库、UI；缺一个“世界留言”实体与查询/审核。
- 设计：`RoadSign` 表（位置、文本、作者、可见性、过期时间、举报状态），AOI 内按距离查询，客户端用世界标记 + 交互面板显示；设置页复用现有开关组件。

### 9.1 画面证据

- P18 02:48–02:50 的「江湖悬赏」页可直接读出四类悬赏：**试炼 / 营生 / 仇杀 / 同游**；表单字段：悬赏对象（常生/诬陷）、悬赏事由（解决诬陷-文士 / 被诬陷偷猎动物）、推荐文士造诣（4100）、完成时限（30 分 00 秒）、悬赏消耗、悬赏附言、底部「Space 发布悬赏」。

### 9.2 设计要点

1. **律令/犯罪记录**：把“偷窃/攻击 NPC/违法”转成可查询的记录，而不是即时惩罚。
2. **悬赏市场**：玩家/系统挂赏金，其他人接单追捕；形成 PvP 理由。
3. **海捕/差役**：NPC 执法者介入，避免只有玩家私斗。
4. **状态可见**：被悬赏者 HUD 有红色标记，知道自己在被追。

### 9.3 对我们的映射

- 我们有 `MonsterAiCore`、`NpcEditor`、`Selection`、`CombatGrain`，但无犯罪/悬赏。
- 建议先在“安全区外 + PvP 开关”基础上做最小闭环：犯罪记录 → 悬赏单 → 击杀 → 赏金结算 → 通缉状态 HUD。需要服务器权威判定（谁先攻击、是否红名）。

### 10.2 设计要点

- 建议先接 `MarketGrain` 只读（搜索/我的挂单），再做购买/结算；交易先做点对点（TradeGrain）。

## 12. 联网玩法的设计原则总结

1. **入口分层**：侠境/试剑/止戈/闯荡/闲趣 + 同游聚合页 + 世界层，玩家不需要背系统名。
2. **规模徽标**：5/10 人、周本/日常、推荐战力，入口即信息。
3. **周常骨架**：首通、周上限、赛季积分，三层目标。
4. **防刷优先**：心力、周限购、周上限、赛季经验上限。
5. **低成本社交**：路牌、闲趣、协助清剿，让“不组队也能感到有人在”。
6. **PvP 有理由**：悬赏/海捕给 PvP 一个世界内的动机，而不是只有竞技场。
7. **外观与战力分离**：商城主要卖外观/便利，战斗材料靠玩法。
