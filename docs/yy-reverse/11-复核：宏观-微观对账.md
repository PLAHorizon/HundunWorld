## 4. 细节与宏观如何“遥相呼应”（三个例子）

### 4.1 双轨世界：宏观一句话，微观三层证据

宏观：“单人/多人双轨，叙事与联网解耦。”

微观三层：

1. **地图层**：地图上并排「单人/多人」（P02 00:54、P24 00:18）；
2. **入口层**：世界模式选择页「单人模式 / 多人模式」（P11 04:28）；
3. **数值层**：单人模式等级独立、20 级后不再获得（P11 04:36）；角色等级/天赋是另一条线（P07 00:12）。

三层同时成立，宏观结论才成立；只看到地图页签就下结论是不够的。

### 4.2 活动分层：宏观五个词，微观五张脸

宏观：“侠境/试剑/止戈/闯荡/闲趣 + 同游聚合。”

微观：

- 顶部导航五个词（P11 01:42）；
- 同游页四卡 + 四海笺（P11 01:34）；
- 侠境 10 人、智能助战、缺治疗（P11 01:42–02:06）；
- 闯荡页群力共伐 2/2（P11 04:10）；
- 挑战页心力 447/600（P11 00:12）。

如果只看到同游页，很容易把“同游”误当成第五个顶级入口；必须同时看顶部导航与闯荡页，才能得到正确层级。**这正是本轮重跑修正的核心。**

### 4.3 经济闸门：宏观“三层”，微观四组数字

宏观：“周上限 + 周限购 + 赛季/战令/和鸣上限。”

微观：

- 通宝：32,208 / 220,000，且明确排除心力/掉落/一次性/兑换（P04 01:56）；
- 不肝商店：周限购 40/40（P11 02:28）；
- 战令：本周上限 0/18,000（P11 04:04）；
- 和鸣：本周上限 0/2,000（P11 03:52）；
- 四海笺：每周获得 0/1000（P11 01:34）。

四组数字分别属于不同系统，但共同支撑“多层闸门”这个宏观判断；缺任何一组，结论都会偏。

- 主视频 25P 引用：**399 条**（首轮 333 + 复核新增 66），0 条越界/未知分P。
- 高密度引用：P11（核心）、P04（经济）、P02/P03（操作/战斗）、P07/P08/P09/P10（养成）、P12/P18/P22/P24（社交/地图）。
- 未引用/低引用：P01（片头）、P13/P15/P19/P20/P21（纯单人），P17（网易 DD 工具），P23（本轮已补 UI 结构）、P14/P16（只取地图/分类）。
- 次视频：103P 中抽样 20 集 × 2 段（40 段）。内容以单人剧情为主，未提供新的联网系统；仅用于 HUD/视觉/开放世界的旁证。**因此联网结论仍以主视频为准。**

### 6.1 次视频第二轮复核

- 抽样方式：20 集 × 2 个时间点（约 25% / 65%），每段 90 秒，共 40 段；另有 2 段片头测试片段。
- 复核结果：
  - 能看到开放世界移动、洞窟探索、战斗 HUD、对话演出、地图/任务追踪；
  - 未看到 10 人侠境、组队界面、同游聚合、闯荡列表、路牌、海捕等联网系统；
  - 42 段总览见 `evidence/secondary_overview.jpg`：可见洞窟/城镇/战斗/演出/时间盘/漫画面板，但**没有**组队、10 人侠境、路牌、海捕等联网界面。
  - 因此次视频只能作为“HUD/视觉/开放世界表现”的旁证，不能作为联网玩法结论的来源。
- 结论：主视频负责“联网系统与 UI 结构”，次视频负责“世界/战斗/HUD 的跨场景一致性”；两者分工明确，避免把剧情片段误当成联网证据。

## 7. UI 重铸准入门槛

### 7.1 可直接进入重铸（已证）

1. **活动中心 IA**：五入口 + 同游四卡 + 闯荡列表 + 挑战页（心力）。
2. **HUD 分层**：常驻（小地图/任务/血条/技能轮盘）+ 上下文（Boss/目标/交互）+ 瞬时（伤害/提示）。
3. **列表-详情模板**：钱袋、装备、成就、商店；左侧分类/筛选，右侧详情，底部批量操作。
4. **地图工作台**：单人/多人、图层、区域完成度、分类页签、地点卡、本周目标。
5. **数字上下文**：持有/本周已用/上限/周限购/剩余次数/人数/职责。
6. **异步社交设置**：路牌可见性、举报、加固；悬赏/海捕状态。
7. **支持性 UI**：场景回溯、逃离卡死、重连状态。

### 7.2 需要实机/更多素材验证（不得当成确定规则）

- 据点/野外首领是否必须多人、共享血量/贡献；
- 试剑 5 人本的具体 UI/匹配/心力消耗；
- 止戈各模式的准备/结算/段位 UI；
- 百业帮派/帮派战的具体界面；
- 交易/拍卖的具体流程与税；
- 和鸣/商城/月卡的付费与合规细节；
- 移动端布局/触摸轮盘/性能降级。

### 7.3 准入门槛（建议写进 UI 重铸立项）

- 只对 7.1 的“已证”项做视觉/交互重铸；
- 7.2 的项只做**占位 + 开关 + “待验证”标记**，不得写死规则；
- 每张新页面必须能回指到本对账表的一行（macro → micro → 报告）；
- 重铸后跑 40 页回归 + `ui_tree` 溢出 + 截图取证。
