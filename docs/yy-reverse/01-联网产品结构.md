# 01 · 联网产品结构：双轨世界与活动中心

> 口径：只分析开放世界 / 联网共享内容。单人剧情、残章、奇遇、单人解谜不在本文范围。
>
> 证据标记：【实证】=画面/OCR 直接可见（P 为分 P，时间码为片内时间）；【旁证】=官方/媒体/攻略与画面互证；【推断】=工程反推。

## 1. 结论先行

《燕云十六声》的联网结构不是“所有人同处一个无缝大世界”的传统 MMO，而是：

1. **双轨世界**：地图上直接切换「单人 / 多人」；单人世界承载剧情与单人探索，多人世界承载共享行为（路牌、悬赏、海捕、其他玩家）【实证：P02 00:54、P04 00:02、P14 00:20、P24 00:18、P11 04:28】。
2. **活动中心聚合**：联网玩法不散落在世界里，而是收进「侠境 / 试剑 / 止戈 / 闯荡 / 闲趣」这组入口；「同游」是聚合页（侠境/试剑/止戈/闲趣四卡 + 四海笺周奖励），再通过组队、匹配、房间进入副本或对局【实证：P11 01:34 同游页、01:42 顶部导航、04:10 闯荡页；旁证：17173/九游对 1.5 版本“同游玩法”的更新说明】。
3. **战力与叙事解耦**：存在独立的「单人模式等级」，只影响个人模式、20 级后不再获得，并提供气血/移速/恢复等加成【实证：P11 04:36；P11 04:28 的模式选择页】。联网养成走另一条线（角色等级、装备、武学、心法、奇术）。
4. **强周常/赛季节奏**：通宝周上限、战令周经验上限、和鸣周上限、侠境/试剑周首通、赛季积分分段，构成“每天有小事、每周有上限、每季有目标”的节奏【实证：P04 01:56、P11 01:42、P11 03:52、P11 04:04】。

对 HundunWorld 的启示：**我们不该照搬“双轨世界”**（我们是单一大世界、服务器权威同步），但应照搬它的 **活动分层、组队/匹配入口、周常上限与赛季目标**，并把“单人安全区 / 组队内容”在 UI 上显式标注。

## 2. 双轨世界：单人 / 多人如何切换

### 2.1 画面证据

| 证据 | 画面内容 | 说明 |
|---|---|---|
| P02 00:54 | 地图左上角并排「单人 / 多人」两个页签 | 切换发生在**地图层**，不是登录层 |
| P04 00:02 | 同一地图，仍为「单人 / 多人」 | 两个世界共用同一张地图与区域完成度 |
| P11 04:28 | 世界模式选择：单人模式 / 多人模式 | 切换发生在世界入口，不只是地图筛选 |
| P14 00:20 | 地图「单人 / 多人」，多人页出现玩家头像点 | 多人世界可看到其他玩家位置 |
| P24 00:18 | 地图多图层（一层/二层/三层）与区域完成度 | 城市/洞窟有多层地图 |
| P24 03:44 | 夜间地图上出现多个玩家头像与区域 100% | 多人世界是真实共享空间，不是纯大厅 |

### 2.2 单人模式等级（关键设计）

P11 04:36 的「单人模式等级」页显示：

- 当前 20 级 → 可突破到 21 级；
- 文案：“仅影响个人模式，20 级后不再获得”；
- 属性加成示例：气血上限 +20.7%、移速 +22.3%、气血恢复 +7.2%、全部属性 +192/+208；
- 突破奖励按「二阶·燕山 / 三阶·观海 / 四阶·浮岸 / 五阶·梦浮 / 六阶·洞明」发放天赋点【实证：P07 00:16–00:20；P11 04:36】。

> 注：P07 00:12 展示的是**角色等级/天赋点**（等级 21、天赋点 125/85、属性加成），不要与「单人模式等级」混为一谈；两者是不同轨道。

【推断】这是把“单机剧情的数值成长”与“联网养成的数值成长”隔离：避免单人剧情给的角色强度直接碾压 PvP/团本，也避免联网装备反过来破坏剧情体验。

### 2.3 对我们的映射

- 我们只有一个权威世界，**不能**做双世界切换；但可以做“内容标签”：
  - 「单人可完成」：剧情、采集、探索；
  - 「建议组队」：5 人本、10 人本、据点、野外首领；
  - 「强制组队」：团队副本、帮会战。
- 在 HUD/地图/活动入口上显示标签，避免玩家误入高难内容。
- 若未来要做“剧情模式”，应使用**独立数值档位**（类似单人模式等级），而不是复制一个世界。

## 3. 活动分类学：四类玩法 + 闯荡 + 同游聚合

P11 01:42 的顶部导航稳定出现五个词：

> **侠境 · 试剑 · 止戈 · 闯荡 · 闲趣**

而 P11 01:34 的「同游」页是聚合页：四张大卡「侠境 / 试剑 / 止戈 / 闲趣」+ 右上「四海笺每周获得 0/1000」。P11 04:10 的「闯荡」页则列出多人活动：群力共伐、有因必应、天泉特训、福地修炼、五禽戏、红炉雅集、多人会诊、悬壶济世、献艺共舞（群力共伐标注「多人」「每周剩余奖励次数 2/2」）。

结合 P11 01:42 的侠境页、P11 04:24 的「同游」页与公开资料，可还原为：

| 一级入口 | 内容 | 规模/节奏 | 证据 |
|---|---|---|---|
| **侠境** | 团队副本（周本），10 人；另有「挑战」页的镇守/据点入口；每周首通与本周首领奖励 | 10 人，周常 | P11 01:42–02:16；P11 00:12 挑战页；旁证：侠境为 51 级解锁的 10 人团本 |
| **试剑** | 5 人副本，每周首通额外奖励、金色装备爆率更高；可匹配 | 5 人，周常 | P11 01:42 顶部入口；旁证：1.5 版本匹配优化、5 人本心力消耗 |
| **止戈** | PvP：论剑 1v1、觉障林（吃鸡）、争锋、演武、天下争鸣；赛季积分分段 | 1v1 / 多队 / 赛季 | P11 01:42 顶部入口；旁证：止戈=PvP，论剑 1v1、觉障林吃鸡 |
| **闯荡** | 多人活动列表：群力共伐、有因必应、天泉特训、福地修炼、五禽戏、红炉雅集、多人会诊、悬壶济世、献艺共舞 | 多人，周奖励（群力共伐 2/2） | P11 04:10 |
| **同游（聚合页）** | 侠境/试剑/止戈/闲趣四卡 + 四海笺 0/1000；底部「H 发布悬赏」 | 周常 | P11 01:34 |
| **闲趣** | 休闲小游戏：浮景行舟、烟花晚会、雀神争霸、射覆等；支持匹配/邀请/落座 | 随时 | P11 04:16–04:20 卡面；旁证：1.5 版本“闲趣-雀神争霸/射覆”匹配与提示优化 |

此外还有两个跨入口的“世界层”：

| 世界层 | 内容 | 证据 |
|---|---|---|
| **百业（帮派）** | 百业侠境（帮会团本）、百业建造、百业商店、百业战、百业声望/侠名 | P11 04:10「群力共伐」（多人、每周 2 次奖励）；旁证：百业=帮派，百业侠境为公会福利团本 |
| **江湖** | 路牌、悬赏/海捕、江湖悬赏；据点/野外首领在 P16 中呈现为**武林录分类**，其“必须多人”属性未获本视频证实 | P12 路牌；P18 02:32–03:46 海捕；P16 04:12–05:44 武林录分类 |

### 3.1 设计要点

1. **入口少、层级清楚**：顶部五个词（侠境/试剑/止戈/闯荡/闲趣）+ 一个同游聚合页；每个词对应一种“社交强度”（组队 / 对抗 / 多人活动 / 休闲）。
2. **同游是“聚合页”而不是独立玩法**：四卡聚合 + 四海笺周进度，承担“今天玩什么”的决策；闯荡则承担“轻量多人活动”的列表。
3. **每个卡片都带“本周/剩余/人数/推荐”信息**：降低组队前的信息成本（P11 01:42 的 10 人/缺少治疗职责/推荐造诣）。

## 4. 组队、匹配与角色定位

### 4.1 可见信息

- **10 人徽标**直接印在侠境卡片右上角（P11 01:42/02:06），玩家在入口就能知道规模。
- **推荐武学**：P06 00:20–00:34 出现四类定位：
  - 输出近战
  - 输出远程
  - 承伤近战
  - 治疗远程
  每一类下给出主武学/副武学/心法/奇术的搭配方案，并标注“一键应用/查看详情”。
- **协战/协助**：【旁证】1.5 版本公告与攻略提到匹配/补位；本视频 01:42 的侠境页有「智能助战」文案，说明存在“助战/补位”机制。
- **准备阶段规则**（旁证）：1.5 版本公告写明止戈准备阶段禁用技能/奇术、射箭初始精元降为 40%、战斗中精元恢复 +20%；天下争鸣准备场景可切换武学，但治疗职责不超过 1 人。
- **匹配体验**（旁证）：试剑/侠境进入副本后仍可继续匹配；可按首领阶段设置匹配起点。

### 4.2 设计要点

- **定位先于数值**：推荐的是“输出近战/远程、承伤、治疗”这类职责，而不是具体门派；玩家用武学+心法+奇术自由组合，降低“职业锁死”。
- **治疗职责限 1**：防止堆治疗导致副本无解，是 10 人本的关键约束。
- **准备阶段禁用技能**：把“配装/切武学”与“开打”分开，减少开局偷跑。

### 4.3 对我们的映射

我们已有：

- `Horizon.Orleans.Grains/TeamGrain.cs`：CreateTeam/Join/Leave/Kick/TransferLeader/EnterDungeonAsTeam 等完整 API；
- `Horizon.Orleans.Grains/DungeonGrain.cs`：CreateDungeon/玩家集合/Boss 数据；
- 客户端 `MenuTeamPage`、`MultiplayerPage`、`DungeonEntryPage` 仍是设计稿/未接服务端（分别见 `MenuTeamPage.cs:410`、`MultiplayerPage.cs:461/540`、`DungeonEntryPage.cs:472`）。

差距不在“有没有 Grain”，而在 **Handler/协议/客户端服务/匹配队列** 未打通。实施计划应优先把 TeamGrain + DungeonGrain 接到网关，再做匹配与职责标签。

## 5. 内容节奏：日、周、季

| 周期 | 机制 | 证据 |
|---|---|---|
| 每日 | 日常任务、百业任务、觉障林、止戈、心力消耗 | P11 04:04 战令页「每日任务」；旁证：每日/每周日常 |
| 每周 | 侠境/试剑首通；通宝周上限 220,000；战令周经验上限 18,000；和鸣周上限 2,000；本周流派试炼剩余 27 天 | P04 01:56、03:14；P11 04:04；P11 03:52；P24 00:18 侧栏「本期流派试炼 剩余27天」 |
| 赛季 | 「夹钟奏雅·上」2026-03-27 ~ 2026-05-08；赛季积分分档；赛季奖励/专属外观 | P11 01:42；P11 02:22（不肝/心安鲤得·五重境，积分 3614/5000/10000/15000/20000） |
| 商业化 | 月卡、战令、和鸣（抽卡/限定池）、外观、交易、充值 | P11 02:52 商城八页签「推荐/外观/精选/月卡/和鸣/福利/交易/充值」；P11 04:04 战令/月卡；P11 03:40 和鸣 |

### 5.1 设计要点

- **上限是“防肝”而不是“防玩”**：通宝上限文案明确“心力玩法、怪物击杀拾取、红宝、一次性奖励及通宝兑换不纳入上限”（P04 02:08），即上限只约束“可重复刷的日常产出”，不惩罚一次性内容。
- **多轨上限**：货币、战令经验、和鸣积分各自有周上限，避免单一资源被无限刷。
- **赛季重置的是“目标”而不是“资产”**：赛季积分分段给奖励，装备/外观不强制清零（从 UI 推断，未见资产重置提示）。

### 5.2 对我们的映射

我们服务端已有 `CurrencyGrain`、`ActivityGrain`、`DungeonGrain`，但缺少：

- 统一的“周上限”配置与校验（按来源分类，一次性奖励不计入）；
- 战令/赛季（`BattlePass` 页面仍是设计稿）；
- 活动日历与“本周剩余”倒计时（`MenuActivitiesPage` 仍是样例）。

建议新增 `ActivityCaps` 配置（按货币/来源/周期），在 `ShopHandler`/`ItemHandler`/`DungeonGrain` 发奖前统一校验，并回传“本次获得 / 本周已用 / 上限”三元组，供 UI 直接显示。

## 6. 产品结构对我们的三条硬结论

1. **不要复制双轨世界**。我们的核心资产是单一大世界的服务器权威同步；复制双世界会撕裂 AOI、社交与经济。应复制“活动中心 + 内容标签”。
2. **先打通组队/副本，再做匹配**。TeamGrain/DungeonGrain 已有较完整 API，优先接 Handler 与客户端，比新写一套便宜。
3. **周上限与赛季是留存骨架**。没有上限，经济会被刷穿；没有赛季，周常会失去目标。两者应作为 P0 的服务端基础能力，而不是运营活动。
