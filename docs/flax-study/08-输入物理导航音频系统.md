## 一、结论摘要

FlaxEngine 的输入系统提供 Low-Level（直接设备状态）和 High-Level（Virtual Input 映射）两层 API，支持跨平台输入统一。物理系统基于 PhysX 5.1，提供完整的碰撞体、刚体、Character Controller、Raycasting、Trigger、Joint 支持。导航系统支持 NavMesh 分块流式加载、Pathfinding API、NavCrowd 群体导航。AI 系统提供 Behavior Tree 行为树。音频系统支持 3D 空间音频、压缩、流式播放。

**对 MMORPG 的核心价值**：
- 输入系统：角色移动、技能释放、UI 交互的基础
- Character Controller：角色移动碰撞的核心组件
- Raycasting：技能检测、交互拾取
- NavMesh + NavCrowd：NPC/怪物 AI 寻路、群体避让
- Behavior Tree：复杂 AI 行为编排
- 3D 音频：环境音效、技能音效

## 四、导航系统

### 4.1 NavMesh 概念

- **Navigation Mesh**：定义可行走区域的多边形网格
- 支持**运行时生成**和**编辑器预构建**
- 异步构建，不阻塞游戏逻辑
- 支持进度报告

### 4.2 NavMesh Tiles（分块）

- NavMesh 按**场景分块（Tiles）**存储
- 场景加载时，Tiles 流式合并为完整 NavMesh
- 支持**大世界分场景流式加载**
- 导航代理在分块 NavMesh 上正常工作

**MMORPG 意义**：
- 大世界按 Chunk 划分场景
- NavMesh 随 Chunk 加载/卸载
- 无需一次性生成整个世界 NavMesh

**CrowdSystem 实现**：
```csharp
public class CrowdSystem : GamePlugin
{
    private NavCrowd _crowd;
    private CrowdTaskGraphSystem _system;
    
    public int MaxAgents = 25;
    
    internal void AddAgent(Agent007 agent)
    {
        if (_crowd == null)
        {
            // 延迟初始化
            _crowd = new NavCrowd();
            if (_crowd.Init(agent.Properties, MaxAgents))
                throw new Exception("Failed to initialize crowd");
            
            // 添加到 TaskGraph 异步更新
            if (_system == null)
                Engine.UpdateGraph.AddSystem(_system = new CrowdTaskGraphSystem { System = this });
        }
        
        // 添加代理
        agent.AgentID = _crowd.AddAgent(agent.Actor.Position, agent.Properties);
        agent.Crowd = _crowd;
    }
    
    internal void RemoveAgent(Agent007 agent)
    {
        _crowd.RemoveAgent(agent.AgentID);
        agent.Crowd = null;
        agent.AgentID = -1;
    }
    
    public override void Deinitialize()
    {
        Engine.UpdateGraph.RemoveSystem(_system);
        Object.Destroy(ref _system);
        Object.Destroy(ref _crowd);
        base.Deinitialize();
    }
    
    // 异步更新 Crowd
    private sealed class CrowdTaskGraphSystem : TaskGraphSystem
    {
        internal CrowdSystem System;
        
        public override void Execute(TaskGraph graph)
        {
            graph.DispatchJob(UpdateJob);
        }
        
        private void UpdateJob(int i)
        {
            System._crowd.Update(Time.DeltaTime);
        }
    }
}
```

**Agent 实现**：
```csharp
public class Agent007 : Script
{
    internal NavCrowd Crowd = null;
    internal int AgentID = -1;
    private Vector3 _targetPos;
    
    public Actor MoveToTarget;
    public Vector3 Offset = new Vector3(0, 100, 0);
    
    // 代理属性
    public NavAgentProperties Properties = new NavAgentProperties
    {
        Radius = 34.0f,
        Height = 144.0f,
        StepHeight = 35.0f,
        MaxSlopeAngle = 60.0f,
        MaxSpeed = 500.0f,
        CrowdSeparationWeight = 2.0f,
    };
    
    public override void OnEnable()
    {
        PluginManager.GetPlugin<CrowdSystem>().AddAgent(this);
    }
    
    public override void OnDisable()
    {
        PluginManager.GetPlugin<CrowdSystem>().RemoveAgent(this);
    }
    
    public override void OnUpdate()
    {
        if (!MoveToTarget || Crowd == null)
            return;
        
        var currentPos = Actor.Position;
        var targetPos = MoveToTarget.Position;
        
        // 更新目标位置
        if (targetPos != _targetPos)
        {
            _targetPos = targetPos;
            Crowd.SetAgentMoveTarget(AgentID, targetPos);
        }
        
        // 应用 Crowd 计算的位置
        targetPos = Crowd.GetAgentPosition(AgentID) + Offset;
        Actor.AddMovement(targetPos - currentPos);
    }
}
```

### 7.2 角色移动方案

```csharp
public class PlayerMovement : Script
{
    private CharacterController _controller;
    private Vector3 _velocity;
    
    public float MoveSpeed = 500.0f;
    public float JumpForce = 800.0f;
    public float Gravity = -1960.0f;
    
    public override void OnStart()
    {
        _controller = Actor.As<CharacterController>();
    }
    
    public override void OnFixedUpdate()
    {
        // 读取输入
        var moveX = Input.GetAxis("MoveX");
        var moveY = Input.GetAxis("MoveY");
        
        // 计算移动方向（相对相机）
        var forward = Camera.MainCamera.Direction;
        forward.Y = 0;
        forward = Vector3.Normalize(forward);
        var right = Vector3.Cross(Vector3.Up, forward);
        
        var moveDir = forward * moveY + right * moveX;
        
        // 应用重力
        if (_controller.IsGrounded)
        {
            _velocity.Y = 0;
            if (Input.GetAction("Jump"))
                _velocity.Y = JumpForce;
        }
        else
        {
            _velocity.Y += Gravity * Time.FixedDeltaTime;
        }
        
        // 执行移动
        var movement = moveDir * MoveSpeed * Time.FixedDeltaTime;
        movement.Y = _velocity.Y * Time.FixedDeltaTime;
        _controller.Move(movement);
    }
}
```

### 7.3 技能检测方案

```csharp
public class SkillSystem : Script
{
    // 射线技能
    public bool RaycastSkill(float range, LayersMask targetLayers, out Actor target)
    {
        var origin = Actor.Position + Vector3.Up * 100;
        var direction = Actor.Direction;
        
        if (Physics.RayCast(origin, direction, out var hit, range, targetLayers))
        {
            target = hit.Collider.Actor;
            return true;
        }
        target = null;
        return false;
    }
    
    // AOE 技能
    public List<Actor> AOESkill(Vector3 center, float radius, LayersMask targetLayers)
    {
        var targets = new List<Actor>();
        var colliders = Physics.OverlapSphere(center, radius, targetLayers);
        foreach (var col in colliders)
        {
            targets.Add(col.Actor);
        }
        return targets;
    }
}
```

## 八、常见坑点与注意事项

### 输入系统

| 编号 | 坑点 | 说明 |

| 编号 | 坑点 | 说明 |
|------|------|------|
| P4 | Character Controller vs Rigid Body | 角色用 CC，物体用 RB |
| P5 | Mesh Collider 性能 | 尽量用简单碰撞体 |
| P6 | Raycast Layer Mask | 避免射线命中自身 |
| P7 | FixedUpdate 中移动 | 物理移动放 FixedUpdate |

| 编号 | 坑点 | 说明 |
|------|------|------|
| P8 | NavMesh 更新 | 动态障碍物需更新 NavMesh |
| P9 | NavCrowd MaxAgents | 需预估最大代理数 |
| P10 | 异步更新 | NavCrowd 应在 TaskGraph 中更新 |

### 音频系统

| 编号 | 坑点 | 说明 |
|------|------|------|
| P11 | AudioSource 数量 | 控制同时播放数量 |
| P12 | 流式加载 | BGM 使用流式，音效使用加载 |
