# FlaxEngine 动画系统与 UI 框架

> 专题报告：动画状态机、Anim Graph、UI 系统、控件库
> 文档来源：https://docs.flaxengine.com/manual/animation/index.html、https://docs.flaxengine.com/manual/ui/index.html
> 编制日期：2026-07-25

---

## 一、结论摘要

FlaxEngine 动画系统功能完备：Skinned Model 蒙皮模型、Anim Graph 可视化状态机、Animation Retargeting 动画重定向、Root Motion 根运动、Inverse Kinematics 反向动力学、Scene Animation 场景动画。UI 系统基于 UICanvas + UIControl 层级，提供丰富的控件库和布局容器，支持代码创建和 High DPI。

**对 MMORPG 的核心价值**：
- Anim Graph 状态机驱动角色动画（移动/战斗/社交）
- Root Motion 实现精确位移
- Retargeting 复用动画资源
- UI 系统支撑大量游戏界面（背包、技能栏、聊天等）

## 二、动画系统

### 2.1 核心组件

| 组件 | 说明 |
|------|------|
| Skinned Model | 蒙皮模型资产（骨骼+网格+蒙皮权重） |
| Animation | 动画剪辑资产 |
| Anim Graph | 动画蓝图（状态机+混合树） |
| Animated Model | 场景中的动画模型 Actor |
| Skeleton Mask | 骨骼遮罩（局部动画） |
| Bone Socket | 骨骼挂点（武器、特效） |

### 2.2 Skinned Model

蒙皮模型包含：
- 骨骼层级（Skeleton）
- 网格数据（Mesh）
- 蒙皮权重（Skin Weights）
- 材质槽（Material Slots）

**编辑器界面**：
- 预览动画
- 查看骨骼
- 编辑蒙皮权重

### 2.3 Animation

动画剪辑资产：
- 从 FBX 导入
- 支持动画事件（Animation Events）
- 支持动画压缩

**动画事件**：
```csharp
// 动画事件回调
public void OnAnimationEvent(string eventName)
{
    switch (eventName)
    {
        case "FootstepL":
            PlayFootstepSound(true);
            break;
        case "FootstepR":
            PlayFootstepSound(false);
            break;
        case "AttackHit":
            ApplyDamage();
            break;
    }
}
```

### 2.4 Animation Retargeting（动画重定向）

- 将动画从一个骨骼重定向到另一个骨骼
- 复用动画资源（不同体型角色共享动画）
- 配置骨骼映射关系

**MMORPG 应用**：
- 不同种族/体型角色共享动画
- 减少动画制作成本

## 三、Anim Graph（动画蓝图）

### 3.1 概念

Anim Graph 是可视化动画状态机：
- 状态机（State Machine）
- 混合树（Blend Tree）
- 状态转换（Transitions）
- 参数驱动（Parameters）

### 3.2 编辑器界面

- 节点图编辑
- 状态机视图
- 混合树视图
- 预览窗口

### 3.3 Graph Parameters（参数）

| 参数类型 | 说明 |
|----------|------|
| Float | 浮点数（速度、方向） |
| Bool | 布尔值（isGrounded、isAttacking） |
| Int | 整数（状态索引） |
| Vector | 向量 |

**代码访问参数**：
```csharp
var animatedModel = Actor.As<AnimatedModel>();

// 设置参数
animatedModel.SetParameterValue("Speed", 5.0f);
animatedModel.SetParameterValue("isJumping", true);

// 获取参数
float speed = animatedModel.GetParameterValue("Speed");
```

**典型角色状态机**：

### 3.5 Inverse Kinematics（反向动力学）

- 脚部 IK：适应地形
- 手部 IK：抓取物体
- 头部 IK：注视目标

### 3.6 Physics（动画物理）

- 布娃娃物理（Ragdoll）
- 动画驱动物理
- 物理混合

### 3.7 Animation Slots（动画插槽）

- 分层动画
- 上半身/下半身独立
- 叠加动画

### 3.8 Root Motion（根运动）

- 动画驱动角色位移
- 精确的步幅和转向
- 网络同步需特殊处理

```csharp
// 获取 Root Motion
var rootMotion = animatedModel.RootMotion;
Actor.Position += rootMotion.Translation;
Actor.Orientation *= rootMotion.Rotation;
```

**MMORPG 注意**：
- 客户端预测需考虑 Root Motion
- 网络同步需发送 Root Motion 数据
- 服务器验证需重放 Root Motion

### 3.9 Scene Animation（场景动画）

- 过场动画
- 相机动画
- 物体动画
- Scene Animation Player 播放

### 5.6 代码创建 UI

```csharp
public class UIManager : Script
{
    private UICanvas _canvas;
    
    public override void OnStart()
    {
        // 创建 Canvas
        _canvas = Actor.AddChild<UICanvas>();
        
        // 创建按钮
        var button = _canvas.AddChild<Button>();
        button.Text = "Click Me";
        button.Size = new Float2(200, 50);
        button.Position = new Float2(100, 100);
        button.Clicked += OnButtonClicked;
        
        // 创建标签
        var label = _canvas.AddChild<Label>();
        label.Text = "Hello World";
        label.Position = new Float2(100, 200);
    }
    
    private void OnButtonClicked()
    {
        Debug.Log("Button clicked!");
    }
}
```

## 七、对 MMORPG 客户端的落地建议

### 7.1 动画架构

```
Anim Graph 层级：
├── Base Layer（基础层）
│   └── Locomotion State Machine
│       ├── Idle
│       ├── Walk/Run（Blend by Speed）
│       ├── Jump
│       └── Fall
├── Combat Layer（战斗层，叠加）
│   └── Combat State Machine
│       ├── Attack Combo
│       ├── Skill
│       ├── Hit React
│       └── Death
└── Additive Layer（附加层）
    ├── Head Look At
    └── Breathing
```

### 7.2 角色动画状态机设计

| 状态 | 转换条件 | 说明 |
|------|----------|------|
| Idle | Speed < 0.1 | 待机 |
| Walk | 0.1 < Speed < 3 | 行走 |
| Run | Speed > 3 | 奔跑 |
| Jump | !isGrounded && VelocityY > 0 | 跳跃 |
| Fall | !isGrounded && VelocityY < 0 | 下落 |
| Attack | AttackInput | 攻击 |
| Skill | SkillInput | 技能 |
| Hit | HitEvent | 受击 |
| Death | Health <= 0 | 死亡 |

### 7.3 UI 架构

```
UI Manager
├── Layer: Background（背景层）
├── Layer: HUD（HUD 层）
│   ├── Health Bar
│   ├── Mana Bar
│   ├── Skill Bar
│   └── Mini Map
├── Layer: Panel（面板层）
│   ├── Inventory
│   ├── Character
│   ├── Quest
│   └── Settings
├── Layer: Popup（弹窗层）
│   ├── Dialog
│   ├── Confirm
│   └── Toast
└── Layer: Top（顶层）
    ├── Loading
    └── System Message
```

### 7.4 UI 管理规范

| 规范 | 说明 |
|------|------|
| 面板栈 | 后开先关，支持返回 |
| 焦点管理 | 同时只有一个面板接收输入 |
| 资源管理 | 面板资源按需加载/卸载 |
| 适配 | 使用 Canvas Scaler 适配分辨率 |
| 动画 | 面板开关使用动画过渡 |

### 7.5 UI 性能优化

| 优化项 | 说明 |
|--------|------|
| 减少控件数 | 合并简单控件 |
| 避免频繁重建 | 复用控件 |
| 图集 | UI 图标使用图集 |
| 裁剪 | 不可见控件不渲染 |
| 批处理 | 相同材质控件合批 |
