# FlaxEngine 脚本系统与生命周期

> 专题报告：C# 脚本开发、生命周期、API 使用方式、多线程
> 文档来源：https://docs.flaxengine.com/manual/scripting/index.html
> 编制日期：2026-07-25

---

## 一、结论摘要

FlaxEngine 的脚本系统以 C# 为主要开发语言（C# 12 + .NET 8），脚本继承自 `Script` 基类，附加到 Actor 上运行。生命周期事件清晰（OnAwake → OnEnable → OnStart → Update 循环 → OnDisable → OnDestroy），执行顺序有明确规则（初始化父先于子，游戏逻辑顺序不确定）。多线程支持完善（JobSystem、TaskGraph、async/await、Thread），但有主线程约束（Actor/Script 添加/移除必须在主线程）。

**对 MMORPG 的核心价值**：
- 生命周期决定初始化/清理时机，影响网络注册、资源加载
- 多线程用于 AI 寻路、地形生成、网络 IO 等异步任务
- 主线程约束决定 ECS 与 Actor 桥接的设计

## 二、脚本基础

### 2.1 创建脚本

脚本是附加到 Actor 的行为组件，继承自 `Script` 基类：

```csharp
using FlaxEngine;

public class MyScript : Script
{
    // 序列化字段（编辑器可见）
    public float Speed = 5.0f;
    
    [Tooltip("移动方向")]
    public Vector3 Direction = Vector3.Forward;
    
    // 私有字段（不序列化）
    private float _timer;
    
    public override void OnUpdate()
    {
        _timer += Time.DeltaTime;
        Actor.Position += Direction * Speed * Time.DeltaTime;
    }
}
```

### 2.2 脚本属性与字段

| 修饰符 | 说明 |
|--------|------|
| `public` | 序列化，编辑器可见 |
| `[SerializeField] private` | 序列化，编辑器可见 |
| `[NonSerialized] public` | 不序列化 |
| `[Tooltip("...")]` | 编辑器提示 |
| `[Range(min, max)]` | 范围限制 |
| `[Header("...")]` | 分组标题 |

### 2.3 访问场景对象

```csharp
// 获取父 Actor
var parent = Actor.Parent;

// 获取子 Actor
var child = Actor.GetChild(0);
var childByName = Actor.GetChild("ChildName");

// 获取脚本
var script = Actor.GetScript<MyScript>();
var scripts = Actor.GetScripts();

// 查找场景中的 Actor
var actor = Level.FindActor("ActorName");

// 查找脚本
var script = Level.FindScript<MyScript>();
```

### 2.4 创建和销毁对象

```csharp
// 创建 Empty Actor
var actor = new EmptyActor();
actor.Name = "MyActor";
actor.Parent = Level;  // 添加到场景

// 从 Prefab 创建
var instance = PrefabManager.SpawnPrefab(prefab, position, rotation);

// 销毁
Destroy(actor);
// 或延迟销毁
Destroy(actor, 5.0f);  // 5秒后销毁
```

## 三、生命周期详解

### 3.1 事件函数列表

| 事件 | 说明 | 调用时机 |
|------|------|----------|
| `OnAwake()` | 对象加载后初始化 | 加载后、启用前，仅一次 |
| `OnEnable()` | 对象启用 | 每次启用时 |
| `OnDisable()` | 对象禁用 | 每次禁用时 |
| `OnDestroy()` | 对象销毁前 | 销毁时，仅一次 |
| `OnStart()` | 首次 Update 前 | 启用后、首次 Update 前，仅一次 |
| `OnUpdate()` | 每帧更新 | 每帧（需启用） |
| `OnLateUpdate()` | 每帧延迟更新 | Update 之后 |
| `OnFixedUpdate()` | 固定帧率更新 | 物理更新时 |
| `OnLateFixedUpdate()` | 固定帧率延迟更新 | FixedUpdate 之后 |
| `OnDebugDraw()` | 调试绘制 | 编辑器调试绘制 |
| `OnDebugDrawSelected()` | 选中时调试绘制 | 编辑器选中时 |

### 3.2 执行顺序

```
┌─────────────────────────────────────────────────────────────┐
│                      初始化阶段                              │
├─────────────────────────────────────────────────────────────┤
│  OnAwake (所有对象)                                          │
│       ↓                                                     │
│  OnEnable (激活的对象)                                       │
│       ↓                                                     │
│  OnStart (首次 Update 前)                                    │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                      游戏逻辑循环                            │
├─────────────────────────────────────────────────────────────┤
│  OnUpdate → OnLateUpdate (游戏更新)                          │
│  OnFixedUpdate → OnLateFixedUpdate (物理更新)                │
│  OnDebugDraw / OnDebugDrawSelected (渲染，编辑器)            │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                      反初始化阶段                            │
├─────────────────────────────────────────────────────────────┤
│  OnDisable (禁用时)                                          │
│       ↓                                                     │
│  OnDestroy (销毁时)                                          │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 关键规则

| 规则 | 说明 |
|------|------|
| OnAwake/OnStart 仅一次 | 不会重复调用 |
| OnEnable/OnDisable 可多次 | 启用/禁用切换时调用 |
| 初始化：父先于子 | 父 Actor 的 OnAwake/OnEnable/OnStart 先调用 |
| 游戏逻辑：顺序不确定 | OnUpdate 等不应依赖调用顺序 |
| OnStart 在 OnEnable 之后 | 首次 OnEnable 后、首次 OnUpdate 前 |
| 编辑时不调用 | 除非标记 `[ExecuteInEditMode]` |
| 反序列化后调用 | 事件调用时脚本数据已就绪（OnAwake 除外） |

### 3.4 MMORPG 初始化编排建议

```csharp
public class PlayerCharacter : Script
{
    public override void OnAwake()
    {
        // 1. 自身初始化（不依赖其他对象）
        // - 组件缓存
        // - 内存预分配
    }
    
    public override void OnEnable()
    {
        // 2. 注册事件/系统
        // - 网络注册：NetworkReplicator.AddObject(this)
        // - 事件订阅
        // - 输入绑定
    }
    
    public override void OnStart()
    {
        // 3. 跨对象交互
        // - 获取其他对象引用
        // - 初始状态同步
    }
    
    public override void OnUpdate()
    {
        // 4. 每帧逻辑
        // - 输入处理
        // - 状态更新
        // - 动画驱动
    }
    
    public override void OnFixedUpdate()
    {
        // 5. 物理相关
        // - 移动计算
        // - 碰撞检测
    }
    
    public override void OnDisable()
    {
        // 6. 清理注册
        // - 网络注销：NetworkReplicator.RemoveObject(this)
        // - 事件退订
        // - 输入解绑
    }
    
    public override void OnDestroy()
    {
        // 7. 资源释放
        // - 释放非托管资源
        // - 清理引用
    }
}
```

## 四、多线程编程

### 4.1 主线程约束

| 操作 | 线程要求 |
|------|----------|
| 编辑 Actor/Script | 仅主线程 |
| 添加/移除 Actor 到场景 | 仅主线程 |
| 创建 Actor/Script | 任意线程 |
| 生成内容（模型等） | 任意线程 |
| 使用 `Scripting.InvokeOnUpdate()` | 回到主线程 |

### 4.2 JobSystem

适用于简单并行任务（一帧内完成）：

```csharp
public override void OnEnable()
{
    // 分发 30 个并行任务
    var label = JobSystem.Dispatch(i => 
    {
        // 并行处理
        ProcessData(i);
    }, 30);
    
    // 等待所有任务完成
    JobSystem.Wait(label);
}
```

**特点**：
- 每 CPU 一个线程
- 适合数据并行处理
- 等待会阻塞当前线程

### 4.3 TaskGraph

适用于复杂依赖图（与引擎系统并行）：

```csharp
private class MyGameplaySystem : TaskGraphSystem
{
    public override void PreExecute(TaskGraph graph)
    {
        // 执行前准备
    }
    
    public override void Execute(TaskGraph graph)
    {
        // 分发异步任务
        graph.DispatchJob(i => ProcessData(i), 30);
    }
    
    public override void PostExecute(TaskGraph graph)
    {
        // 执行后清理
    }
}

// 注册到引擎更新图
_system = new MyGameplaySystem();
Engine.UpdateGraph.AddSystem(_system);

// 可设置依赖关系
//_system.AddDependency(Animations.System);  // 在动画系统后执行
//Particles.System.AddDependency(_system);   // 在粒子系统前执行
```

**特点**：
- 与引擎系统并行执行
- 支持依赖关系
- 更好的 CPU 利用率

### 4.4 async/await

适用于 IO 密集型异步操作：

```csharp
private Task _task;

public override void OnEnable()
{
    _task = Task.Run(HandleFileAsync);
}

public override void OnDisable()
{
    _task.Wait();
}

async Task HandleFileAsync()
{
    Debug.Log("Starting async job");
    
    // 异步文件读取
    using (StreamReader reader = new StreamReader(filePath))
    {
        string content = await reader.ReadToEndAsync();
        // 处理数据...
    }
    
    // 回到主线程
    Scripting.InvokeOnUpdate(() => 
    {
        // 更新场景对象
        UpdateSceneObjects();
    });
}
```

### 4.5 Thread

适用于需要精细控制的长时任务：

```csharp
private Thread _thread;

public override void OnEnable()
{
    _thread = new Thread(LongRunningTask);
    _thread.Start();
}

public override void OnDisable()
{
    _thread.Join();
}

void LongRunningTask()
{
    // 长时运行任务
    while (!_cancellationToken.IsCancellationRequested)
    {
        // 处理...
        Thread.Sleep(16);
    }
}
```

### 4.6 同步原语

| 原语 | 用途 |
|------|------|
| `Semaphore` | 控制并发访问数 |
| `Mutex` | 互斥锁 |

## 七、对 MMORPG 客户端的落地建议

### 7.1 脚本架构

```
Script 基类
├── NetworkScript        # 网络同步脚本基类
│   ├── PlayerCharacter  # 玩家角色
│   ├── RemoteCharacter  # 远程角色
│   └── NetworkedProp    # 网络道具
├── UIScript             # UI 脚本基类
│   ├── Panel            # 面板
│   └── HUD              # HUD 元素
├── EffectScript         # 特效脚本基类
└── SystemScript         # 系统脚本基类
    ├── InputManager     # 输入管理
    ├── AudioManager     # 音频管理
    └── ResourceManager  # 资源管理
```

### 7.2 多线程使用场景

| 场景 | 推荐方式 | 说明 |
|------|----------|------|
| AI 寻路 | TaskGraph | 与引擎并行，支持依赖 |
| 地形生成 | JobSystem | 数据并行，一帧内完成 |
| 网络 IO | async/await | IO 密集，异步等待 |
| 资源加载 | async/await | 异步加载，回调更新 |
| 物理计算 | 引擎内建 | PhysX 已多线程 |
| 粒子模拟 | 引擎内建 | 已使用 TaskGraph |

### 7.3 性能注意事项

1. **避免 OnUpdate 中分配内存**：使用对象池
2. **缓存组件引用**：OnAwake 中缓存，避免每帧查找
3. **合理使用 FixedUpdate**：物理相关逻辑放 FixedUpdate
4. **控制脚本数量**：合并相关逻辑，减少脚本实例
5. **使用 Profiler 定位热点**：定期分析 CPU 耗时

## 八、常见坑点与注意事项

| 编号 | 坑点 | 说明 |
|------|------|------|
| P1 | OnUpdate 顺序不确定 | 不要依赖脚本间 OnUpdate 调用顺序 |
| P2 | OnAwake 时其他对象未就绪 | OnAwake 中不要访问其他对象 |
| P3 | 子线程不能修改场景 | 必须回到主线程添加/修改 Actor |
| P4 | Destroy 不是立即销毁 | 标记销毁，帧末实际销毁 |
| P5 | 编辑时不调用事件 | 除非标记 [ExecuteInEditMode] |
| P6 | C++ 脚本需设置 tick 标志 | C++ 中需在构造函数设置 _tickUpdate 等 |
