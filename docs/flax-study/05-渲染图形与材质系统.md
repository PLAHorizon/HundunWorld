# FlaxEngine 渲染图形与材质系统

> 文档来源：https://docs.flaxengine.com/manual/graphics/index.html
> 编制日期：2026-07-25

---

## 一、结论摘要

FlaxEngine 采用 Deferred Shading（延迟渲染）管线，支持 DirectX 11/12、Vulkan、WebGPU 多后端。材质系统基于 PBR（物理渲染），支持 Instanced Materials、Material Functions、Layered Materials。光照支持全局光照（GI）、反射环境、雾效。后处理系统完整。粒子系统支持 CPU（≤200K）和 GPU（≤5000K）两种模拟方式。

**对 MMORPG 的核心价值**：
- Deferred 管线适合复杂光照场景
- Instanced Materials 减少 Draw Call
- GPU 粒子支持大规模特效
- 多后端支持跨平台发布

## 四、材质系统

### 4.1 材质基础

材质定义物体表面的视觉属性：
- 颜色（Color/Albedo）
- 粗糙度（Roughness）
- 金属度（Metalness）
- 法线（Normal）
- 自发光（Emissive）
- 环境光遮蔽（AO）

### 4.2 材质属性

| 属性 | 说明 |
|------|------|
| Blend Mode | 混合模式（Opaque、Transparent、Additive 等） |
| Shading Model | 着色模型（Lit、Unlit、Foliage 等） |
| Two Sided | 双面渲染 |
| Wireframe | 线框模式 |

### 4.3 材质输入

| 输入 | 说明 |
|------|------|
| Color | 基础颜色 |
| Mask | 遮罩 |
| Emissive | 自发光 |
| Metalness | 金属度 |
| Specular | 高光 |
| Roughness | 粗糙度 |
| Normal | 法线 |
| Ambient Occlusion | 环境光遮蔽 |
| Refraction | 折射 |
| Position Offset | 位置偏移 |
| World Displacement | 世界位移 |
| Tessellation Multiplier | 细分倍数 |

### 4.4 Instanced Materials（材质实例）

- 基于父材质创建实例
- 只覆盖部分参数
- **减少材质编译和 Draw Call**
- MMORPG 中大量使用（装备换色、NPC 变体）

```csharp
// 代码创建材质实例
var materialInstance = Content.Load<MaterialInstance>(instanceId);
materialInstance.SetParameterValue("Color", Color.Red);
```

### 4.5 Material Functions（材质函数）

- 可复用的材质节点组
- 类似函数/子程序
- 提高材质编辑效率

### 4.6 Layered Materials（分层材质）

- 多层材质混合
- 适用于地形、复杂表面
- 每层可有独立纹理和属性

### 4.7 Shader Code in Materials

- 材质中可嵌入 HLSL 代码
- 自定义计算逻辑
- 高级效果实现

## 九、粒子系统

### 9.1 三层结构

```
Particle System（粒子系统资产）
    └── Particle Emitter（粒子发射器）×N
            └── Particle Effect Actor（场景中的特效实例）
```

### 9.2 CPU vs GPU 粒子

| 特性 | CPU 粒子 | GPU 粒子 |
|------|----------|----------|
| 延迟 | 低 | 高吞吐 |
| 最大粒子数 | 200K | 5,000K |
| 适用场景 | 小型特效 | 大型模拟 |
| 场景纹理采样 | 不支持 | 支持 |
| 深度碰撞 | 不支持 | 支持 |
| 要求 | 无 | Compute Shader + Draw Indirect |

**限制**：
- GPU 粒子不支持 Ribbon（丝带）
- GPU 粒子不支持 Lights（光源）

### 9.3 粒子优化

| 优化项 | 说明 |
|--------|------|
| Capacity | 设置实际需要的粒子容量 |
| LOD | 按距离降低粒子数 |
| Culling | 视锥裁剪 |
| Atlas | 纹理图集减少 Draw Call |

### 9.4 MMORPG 特效预算

| 场景 | 粒子预算 |
|------|----------|
| 角色技能 | ≤ 5,000 粒子/特效 |
| 环境特效 | ≤ 10,000 粒子/区域 |
| 同屏总量 | ≤ 50,000 粒子 |
