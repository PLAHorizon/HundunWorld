## 一、结论摘要

FlaxEngine 提供完整的性能分析工具链：内建 Profiler 窗口（CPU/GPU/Network/Memory）、Tracy 深度分析、dotTrace 集成。构建系统 Flax.Build 支持多平台、多模块、增量构建。Game Cooker 提供一键打包、Presets 配置、Custom Defines（Client/Server 分离）。调试支持脚本断点、DebugDraw、网络日志。

**对 MMORPG 的核心价值**：
- Profiler + Tracy 定位性能瓶颈
- Custom Defines 实现 Client/Server 分离构建
- 增量构建加速开发迭代
- Network Profiler 分析同步性能

## 二、性能分析工具

### 2.1 Profiler 窗口

**打开方式**：编辑器 → Window → Profiler

**标签页**：

| 标签页 | 说明 |
|--------|------|
| CPU | CPU 耗时分析 |
| GPU | GPU 耗时分析 |
| Network | 网络数据传输分析 |
| Memory | 内存使用分析 |

**CPU Profiler**：
- 每帧各系统耗时
- 脚本 OnUpdate 耗时
- 物理模拟耗时
- 动画更新耗时

**GPU Profiler**：
- Draw Call 数量
- 三角形数
- 渲染通道耗时
- 着色器耗时

**Network Profiler**：
- 每帧发送/接收字节数
- 对象复制统计
- RPC 调用统计

**Memory Profiler**：
- 资源内存占用
- 纹理内存
- 网格内存
- 动画内存

### 2.2 Tracy

**Tracy** 是深度性能分析工具：
- 帧时间线

- 内存分配追踪

**使用方式**：
1. 构建时启用 Tracy 支持
2. 运行游戏
3. Tracy 客户端连接分析

**待验证**：Flax 中 Tracy 的集成深度和配置方式

### 2.3 dotTrace

## 三、性能优化策略

### 3.1 CPU 优化

| 策略 | 说明 |
|------|------|
| 对象池 | 避免频繁 new/GC |
| 缓存引用 | OnAwake 缓存组件引用 |
| 减少脚本数 | 合并相关逻辑 |
| 合理使用 FixedUpdate | 物理逻辑放 FixedUpdate |
| 异步处理 | 耗时操作异步化 |
| 避免 LINQ | 热路径避免 LINQ |
| 结构体 vs 类 | 小数据用结构体 |

### 3.2 GPU 优化

| 策略 | 说明 |
|------|------|
| 减少 Draw Call | 合批、实例化 |
| LOD | 多级细节 |
| 纹理压缩 | BC1-BC7 |
| 纹理图集 | 减少材质切换 |
| Shader 优化 | 减少指令数 |
| 后处理控制 | 按需启用 |
| 粒子预算 | 控制同屏粒子数 |

### 3.3 内存优化

| 策略 | 说明 |
|------|------|
| 资源卸载 | 场景切换时卸载 |
| 纹理流式 | 按距离加载精度 |
| 对象池 | 复用对象 |
| 资源压缩 | 压缩网格/动画 |
| 引用计数 | 避免资源泄漏 |

### 3.4 网络优化

| 策略 | 说明 |
|------|------|
| AOI | 只同步视野内对象 |
| 频率控制 | 按重要性调整同步频率 |
| 数据压缩 | 压缩同步数据 |
| 增量同步 | 只发送变化数据 |
| 通道选择 | 高频用 Unreliable |

## 五、Flax.Build 构建系统

### 5.1 核心概念

| 概念 | 说明 |
|------|------|
| Target | 构建目标（可执行文件或库） |
| Module | 代码模块（编译单元） |
| .Build.cs | 构建脚本（C#） |
| BuildOptions | 构建选项 |

### 5.2 构建脚本示例

```csharp
// Game.Build.cs
using Flax.Build;
using Flax.Build.NativeCpp;

public class Game : GameModule
{
    public override void Setup(BuildOptions options)
    {
        base.Setup(options);
        
        // 添加模块依赖
        options.PublicDependencies.Add("Networking");
        
        // 添加系统引用
        options.ScriptingAPI.SystemReferences.Add("System.Threading.ThreadPool");
        
        // 添加自定义定义
        options.ScriptingAPI.Defines.Add("GAME_CLIENT");
        
        // 启用网络代码生成
        Tags["Network"] = string.Empty;
    }
}
```

### 5.3 Target 配置

```csharp
// GameTarget.Build.cs
using Flax.Build;

public class GameTarget : GameProjectTarget
{
    public override void Setup(TargetOptions options)
    {
        base.Setup(options);
        
        // 添加模块
        Modules.Add("Game");
        
        // 条件模块
        if (Configuration.CustomDefines.Contains("SERVER"))
            Modules.Add("GameServer");
        else
            Modules.Add("GameClient");
    }
}
```

### 5.4 Custom Defines（Client/Server 分离）

```csharp
// 条件编译
#if SERVER
    // 服务器代码
#else
    // 客户端代码
#endif

// 条件模块引用
if (Configuration.CustomDefines.Contains("SERVER"))
    options.PrivateDependencies.Add("GameServerModule");
else
    options.PrivateDependencies.Add("GameClientModule");
```

## 六、Game Cooker（游戏打包）

### 6.1 功能特性

| 特性 | 说明 |
|------|------|
| 易用 | 编辑器内一键打包 |
| 可配置 | Presets 配置 |
| 命令行 | 支持 CI/CD |
| 增量构建 | 只构建变化部分 |

| 内容加密 | 资源加密 |
| 内容压缩 | 资源压缩 |
| 多平台 | 一次配置多平台构建 |

### 6.2 打开方式

- 编辑器菜单：Window → Game Cooker
- 或：Tools → Game Cooker

### 6.3 Build 模式

快速构建：
1. 选择目标平台
2. 选择配置（Debug/Release）
3. 选择输出目录
4. 点击 Build

### 6.4 Presets 配置

- 存储在 Build Settings 资产
- JSON 格式，适合版本控制
- 每个 Preset 包含多个 Target
- 每个 Target 有独立配置

**典型 Presets**：
```
Development
├── Windows (Debug)
└── Windows (Development)

Release
├── Windows (Release)
├── Linux (Release)
└── Android (Release)

Server
└── Windows Server (Release, SERVER define)
```

### 6.5 命令行构建

```bash
# 命令行构建（用于 CI/CD）
FlaxEditor.exe -build -preset="Release" -target="Windows"
```

### 9.2 命令行构建脚本

```powershell
# build.ps1
param(
    [string]$Preset = "Release",
    [string]$Target = "Windows"
)

# 编译脚本
& "FlaxEditor.exe" -build -preset=$Preset -target=$Target

# 检查构建结果

    Write-Error "Build failed"
    exit 1
}

Write-Host "Build succeeded"
```
