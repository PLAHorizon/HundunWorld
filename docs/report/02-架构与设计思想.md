# 02 · 架构分层与设计思想

> 章节文档，隶属 [全项目综合报告](../PROJECT_FULL_REPORT_20260926.md)。

## 五层单向依赖（契约与实现物理分离）

- **L0 契约**：Horizon.Core.Abstract / Share / **Game.Message（★双端共享协议）** / IM.Message
- **L1 领域**：Core、Model、Game.ECS（抽象）、Game.ECS.Arch、AI.Kernel
- **L2 基础设施**：Entities（EF）、Mapper、IoT.MQTT、**Orleans.Interface（★Grain 契约）**
- **L3 实现**：Orleans.Grains（100+）、Game.Core（Handler/校验/AOI/共享数值推导）、Game.Sim（确定性模拟核心）
- **L4 宿主**：Silo、Game.Gateway、IM.Gateway、WebApi、WebAdmin

Silo 依赖 10 项目、Gateway 依赖 11 项目。动机：Gateway 作为 Orleans Client 只引契约即可跨进程调 Grain，实现进程间解耦。

## 核心设计思想（八条）

1. **虚拟 Actor 为服务端灵魂**：玩家/实体/业务对象皆 Grain，"用单线程思维写高并发"；Orleans 屏蔽激活/寻址/持久化/容错；租约 90s + Despawn 重试兜底体现分布式最终一致性考量。
2. **双客户端 + 文件凭证注入**：Flax 客户端与耕地启动器不做网络通信，经 `HorizonGame.ini` 传 AuthToken/PassportId/网关列表——启动与运行时彻底解耦，游戏运行链路唯一（TouchSocket→Gateway→Orleans）。
3. **混合 Netcode（项目技术皇冠）**：本地玩家 = 客户端预测→服务端权威回放→回滚修正（0.5m）；远程实体 = 快照→自适应插值。三大关键决策：
   - `MovementFormula.Step()` **客户端/服务端共享同一实现**（FormulaVersion=2、重力 9.81、终端速度 50、禁 SIMD 保跨平台浮点逐位一致）；
   - `MovementValidator` 不依赖 Orleans，可在 Grain/单测/反外挂扫描器复用；
   - 协议 v1→v13 版本化演进（**docs/NETCODE.md 基线仍写 v7，代码已到 v13**），每版修一个真实问题（v4 修单例 Handler characterId 竞态、v6 修 MoveSpeed 未同步）。
4. **双世界 ECS（客户端）**：自研 ECSManager 管视觉（Flax Actor），Arch ECS 管网络权威状态；ArchWorldHost 按 NetworkReceive→FixedUpdate→Update→Render→NetworkSend 五阶段流水线调度，`[ArchSystem]` 反射注册自动排序。动机：逻辑权威与视觉表现分离。
5. **双协议体系 + 双重序列化标注**：SyncPacket（系统高频同步，Kind fast-path 路由不解码）与 MessageUnion（用户请求）分通道互补；每类型同时 `[MemoryPackable]`+`[GenerateSerializer]`，一套类型既走 TCP 又走 Grain 通信。
6. **Observer/Source 适配器 + 有界 Channel fanout**：Grain→Gateway 用 `Channel(8192)+DropOldest` 无锁队列，"丢旧保新"（同步容忍丢帧不容忍延迟，8192≈6.8s@1200pkt/s）；弱网降级：带宽触阈值时快照 20Hz→10Hz，恢复需持续 3s（文档口径 100Kbps；项目记录阈值已提升至 500Kbps，以运行配置为准）。
7. **物理 DLL 分发（引擎限制下的务实妥协）**：Flax Game.csproj 禁 NuGet/ProjectReference，共享库经 `CopyToFlax` MSBuild Target 复制 DLL 到 Flax Tools 目录（`C:\Program Files (x86)\Flax\Flax_1.12\Binaries\Tools`），Game.csproj 用 HintPath 引用，Game.Build.cs 注册 22 个 DLL。
8. **文档同步原则**：docs/ 33 份设计文档 + 客户端内嵌约 30 份，与代码高度同步、注释携带决策依据（如 `#13 修复`、"安全审查 2026-08"），修改架构/netcode/协议时须同步更新对应文档。
