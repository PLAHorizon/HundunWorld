## 四、成熟度评价

| 子系统 | 成熟度 | 关键风险 |
|---|---|---|
| Gateway/Netcode | ★全仓最高 | 会话绑定硬校验未收口 |
| ZoneShard 空间权威 | 高 | 3400 行上帝类、单 shard 重构中 |
| 移动同步链路 | 高 | 文档基线滞后代码（v7 vs v13） |
| 角色/加点/战斗数值 | 高（2026-09-26 收敛后） | **两套角色系统语义重叠（瞬态移动 vs 持久 RPG）为最大架构隐患**；HP 单一权威已有契约测试锁定；两套公式已并一 |
| MMO 玩法（任务/副本/拍卖/公会战/GM） | 中偏低 | 骨架齐、交割 TODO 密集 |
| 花卉电商/支付/IM/IoT/RAG | 高 | 成熟度 > MMO 玩法本身；属存量业务线 |
| 客户端 UI/Ink | 高 | 30 页文案待落地；动画/音频为短板 |
| 内容资产 | 低 | 唯一人偶模型且导入产物易丢失；动画空图史 |
| 工程纪律（横切） | 低 | **短板不在架构，而在纪律** |

**总评**：架构成熟度呈"倒挂"形态——基础设施（netcode/网关/Actor/存储/UI 框架/数值内核）达生产级并有用例守护，上层玩法内容（成长/任务/副本/社交玩法闭环）大量占位。

## 五、路线图建议

1. **安全止血**（第 1 周）：轮换并移除明文凭据、cert.pfx 出库、引入 gitleaks + CI。
2. **数值收口**：实现服务端经验/升级曲线；DS 通道 BuildPlayerStats 注入真实角色属性；"被克"表标准化（伴随金轨迹版本递增）；装备加成接入 `AttributeDerivation`。
3. **玩法交割**：拍卖行/任务/掉落/副本发奖 TODO 接线，游戏内玩法 Grain 补 NPC 服务端模型。
4. **表现补齐**：动画状态机/混合树、音频系统、传统 HUD 技能栏施法接线。
5. **架构债务**：统一两套角色系统（文档边界→[Obsolete]→合并）、IShardRouter、仓库卫生。
