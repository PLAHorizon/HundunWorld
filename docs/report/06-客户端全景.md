## 一、Flax 客户端

### UI 技术体系

- **100% C# 代码构建的 Ink 页面体系**：70+ `RegisterPage`、**75 个 dom-id 导航契约**（`UI/Ink/InkPageRouter.cs`）、星型拓扑（战斗 HUD 为枢纽）、`InkPageShell` 五层结构（背景/暗角/内容/粒子/返回按钮）、墨韵涟漪粒子反馈。
- **1920×1080 设计空间等比缩放**（`UILayout.Scale=min(ScaleX,ScaleY)`；战斗 HUD 顶部对齐防信箱下沉）。
- **设计 Token 水墨风**：深墨黑 #0E1016、鎏金 #C8A858、朱红 #C0392B、纸色 #F5F0E8（`InkWashTheme.cs` 对应设计稿 `hundun-yy-ui/colors_and_type.css`）。
- 旧体系 GameMain UI 与 Prefab 库（60 个 .prefab）并存但进世界后不激活；`popup-*` 弹窗层 8 页不铺墨底。

### 页面全景（设计稿 56 页全部映射、全部有实现文件）

创角/开场 7 页（行囊式角色列表 + 五步创角 gender→face-preset→face-sculpt→name + Loading/分镜参考）；战斗/引导 10 页（combat-hud v1 100%、**combat-hud-traditional 默认枢纽**、V2 77%、guide 系 64–67%、死亡 80%、QTE 80%、点穴 53%、元素视野 50%）；角色养成 9 页（CharacterPanelPage 背包已并入、SkillPanel、外观 95%、备战 94%、门派 85%、装备 42% 排除范围）；任务/图鉴（任务 98%、图鉴 92%、世界地图/罗盘/副本入口）；生活/社交/商城 10+ 页（64–100%）；商业化（抽卡 90%、活动 100%、战令 79%）；弹窗/奖励/系统工具（设置 98%、拍照 89%、F9 UI 画廊）。约 30 页仍有"示例数据待替换为设计初值"的文案落地缺口（`UI-DESIGN-LANDING-CHECKLIST-20260923.md`）。

### 传统 HUD 布局（默认主界面）

左上角色面板 → 顶部中央罗盘带（方位+POI+坐标条，置顶距离 10px）→ 右上 160px 圆形小地图+8 环绕按钮 → 左下聊天框（7 频道 Tab：附近/世界/门派/队伍/团队/密聊/系统）→ 右下功能按钮（含沉浸模式切换，传统⇄V2 互切）→ 底部经验条。快捷键：C=角色/行囊、F9=UI 画廊、-=切头顶名牌。

### 登录 → 选角 → 主界面流程

`GameSceneManager` 场景表：Login=`Content/Maps/Login.scene`、Character/Creation=`Character.scene`、GameWorld=`World.scene`。登录面板为浅色水墨青绿全屏三栏（100% 还原 `hundun-login/pages/login.html`），支持 `HorizonGame.ini` 启动器凭证自动登录；选角/创角走行囊式 Cc 流程；进世界初始化水墨 UI，枢纽默认 CombatHudTraditional。

### 3D 角色预览（现役 CharacterPreview3D，1415 行）

SceneRenderTask 离屏渲染（CustomActors 白名单不污染主场景）+ 自建三点光 + 显式 BindSceneSky + 场景卸载野指针防护；**禁用动画图、程序化待机**（缓存基准骨骼矩阵后逐帧叠加呼吸微动）；拖拽旋转 0.01 rad/px、俯仰限 −18°~26°；Ry(180)·Rx(180) 姿态校正；另有 Viewport3DPreview/CharacterPreviewPanel 两代遗留实现并存。MetaHuman 为材质/JSON 预设框架（Preset_{Default,Asian,European}.json），无实模。

### 玩法交互

- **第三人称相机**：ThirdPersonCamera（3900+ 行：碰撞射线三档 Low/Medium/High=1/5/9、异步缓存、震屏、弹簧臂、DynamicCameraAdjuster）。
- **点击移动**：Alt+左键，注入与 WASD 等价方向输入走 ECS 主链路；无烘焙 NavMesh 故直线移动；看门狗 25s/到达半径 120；`ClickToMoveDestinationMarker.cs` 目的地标记进行中（未提交）。
- **游戏内聊天**：完整接线（`Social/ChatClient.cs` ↔ ChatGrain，发送/历史/撤回/举报/静音/未读，传统 HUD 7 频道渲染）；旧 `ChatSystem.cs` 本地模拟为遗留双轨。
- **移动/轻功/传送**：客户端预测移动（§03）；轻功三段跳+滑翔（半成品，见 §04）；FastTravel 经权威对齐通道上报服务端（防悬空）。
- **本地贴地**：必须经 FastTravel 通道上报服务端权威对齐。

## 二、耕地（GengDi）Avalonia 启动器

- **登录/注册/安全**：LoginView/RegisterView/SecurityView + AccountService/UserSession/ImIdentity（IM UserId=数字 PassportId）。
- **游戏库/启动**：GamesView（安装/更新/卸载/启动）+ GameGatewayClient/GatewayDiscoveryService（经 WebApi `/gateway` 发现 IM/Game 网关）+ GameModelIniWriter 写客户端 ini（文件凭证注入）。

- **12 模块/221 个 .cs/12 个 Repository**：花卉市场（14 View 交易全家桶）、AI 助手、IoT 大屏、IM/通话（`Core/Services/Call/`：CallStateMachine/AudioCallEngine WASAPI→16kHz PCM/VideoCallEngine MF→DShow 回退/UDP 直连传输）、音乐（网易云源+本地扫描）、天气节气、新闻、社交、下载、Excel 工具；LiteDB 本地库；四端壳 PC/Android/HarmonyOS/iOS。
