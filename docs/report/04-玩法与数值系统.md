## 权威模型总前提

**服务端权威**。客户端只发意图（`CombatActionPacket` 仅含 AttackerId/TargetId/ActionKind/SkillId/ClientTick/Yaw），伤害数字全部由服务端结算后回包，客户端 `DamageResponseHandler` 仅做表现（血条/飘字/特效）。

服务端存在两条权威路径（并存，DS 为灰度）：

- **Orleans 路径**：`CombatGrain`（命中/闪避/暴击/格挡/五行）+ `CharacterGrain.RequestHpChangeAsync`（防御减免与 HP 唯一裁决点，有契约测试 `HpSingleAuthorityContractTests` 锁定）。
- **确定性 DS 路径**：`Horizon.Game.Sim/CombatCore.Resolve`（splitmix64 确定性掷骰，同输入序列同结果，为灰度对拍/金轨迹回放设计）。

## 角色属性模型

**运行时组件**（`HundunWorld/Source/Game/Character/Attributes/CharacterAttributesComponent.cs`，客户端真正数据源）：
- 基础：Level、Exp、CurrentHealth/MaxHealth、PhysicalAttack/MagicAttack、PhysicalDefense/MagicDefense
- 能量：CurrentEnergy/MaxEnergy（内力，回复默认 10/s）、CurrentStamina/MaxStamina（体力，回复默认 5/s）
- 五行亲和 Metal/Wood/Water/Fire/Earth（0–10000）
- 成长阶段：武侠 1–50 / 修仙 51–150 / 玄幻 151–300

**服务端持久**：`CharacterEntity`（Level/Experience/RealmLevel/CombatPower/Health/AttackPower/Defense/WuxingElement 0无1金…5土）+ `CharacterAttributeEntity`（表 `Game_HunduShijie_CharacterAttribute`：根骨/悟性/身法/臂力/内劲 + 派生列 命中/闪避/暴击/暴伤/移速/攻速/格挡/韧性/减伤/反伤/气盾/回血/回气 + 五行攻抗 + 五行加点列 MetalPoint…EarthPoint）。

## 加点规则与派生属性公式

**点池**：每级 5 点，`Total = Level × 5`；九项加点：力量/敏捷/体质/内力/金/木/水/火/土。

**每点换算（服务端单一来源 `Horizon.Game.Core/Combat/AttributeDerivation.cs`，2026-09-26 起；客户端 `CharacterAttributesComponent.cs:270-320` 为镜像）**：

| 加点 | 每点效果 |
|---|---|
| 力量 | 生命上限 +20、攻击 +10 |
| 敏捷 | 防御 +20、移速 +3 |
| 体质 | 生命上限 +100 |
| 内力 | 内力上限 +10 |
| 金 | 亲和+10；攻+50、金伤+30、金防+5、破木防+30、暴击率+0.1%、暴伤+3% |
| 木 | 亲和+10；血+300、木伤+20、木防+5、破土防+30、回血+15/s、毒伤几率+0.1%、治疗率+0.2% |
| 水 | 亲和+10；内力+200、水伤+30、水防+5、破火防+30、冰冻几率+0.1%、减速+0.2%（上限70%） |
| 火 | 亲和+10；攻速+2、火伤+30、极速攻击几率+0.1%（触发×3攻速）、破金防+30、移速+5 |
| 土 | 亲和+10；防御+50、土伤+30、土防+5、破水防+30、反伤几率+0.1%（反弹10%） |

**合成公式（基值 + 装备 + 加点三层）**：
- `MaxHealth = base + equip + 力量×20 + 体质×100 + 木×300`
- `PhysicalAttack = base + equip + 力量×10 + 金×50`
- `PhysicalDefense = base + equip + 敏捷×20 + 土×50`
- `MaxEnergy = base + equip + 内力×10 + 水×200`
- `MagicAttack/MagicDefense = base + equip`（**不吃加点，仍未实现**）
- 派生：暴击率=金×0.1%、暴伤=金×3%、回血/s=木×15、移速加成=敏捷×3+火×5

**数据流（权威闭环）**：客户端 `AttributeAllocationService` 只提交**期望终态**（九项全量，协议 235/236）→ 服务端 `CharacterGrain.AllocateAttributeAsync`（校验点池/非负/超池）→ Redis 状态 + SQL 落库 → 回执灌回组件；全零=重置。

## 伤害计算（2026-09-26 收敛后）

**统一口径 = CombatCore**：`基础伤 = 攻击×0.5 + 技能附加`；`伤害 = 基础 × 五行 × (1 − 防/(防+100))`；暴击 ×倍率（默认 1.5）；格挡 ×0.5；`round` 后**保底 1 点**；真实伤害穿透免疫防御。

- **CombatGrain（Orleans 路径）**：闪避→基础伤→五行（仅 elementType>0）→格挡→暴击；防御减免统一交给 `RequestHpChangeAsync`（避免双重减免）。**2026-09-26 起** `GetOrCreateCombatInfo` 不再硬编码：攻击/防御/生命上限/内力 = 角色基础值 + `AttributeDerivation` 加点派生；暴击率/暴伤倍率 = 属性表列值（未落列时保留默认 0.1/1.5）+ 金系加点；闪避/格挡 = 属性表列值（默认 0.05/0.1）。
- **CharacterGrain.RequestHpChangeAsync**：减免所用防御 = 基础防御 + 加点派生防御（敏捷/土系）——与 CombatGrain 同源（`AttributeDerivation`）。
- **CombatCore（DS 确定性路径）**：完整链（合法性/距离/朝向扇区→闪避→伤害→暴击），掷骰 splitmix64。
- **CombatSystemGrain（P1.4）**：**已收敛**——原"减法式" `Attack − Defense×100/(Defense+100)` 改为 CombatCore 口径乘法式（2026-09-26）。
- **客户端 DamageCalculator（本地预览，非权威）**：五行倍率已对齐服务端 1.25/0.8/相生 1.15（2026-09-26）；防御减免 `×100/(100+Def)` 与乘法式同形；仍有 ±10% 随机波动与抗性上限 75% 等本地表现项。

## 五行系统

枚举：None=0 金1 木2 水3 火4 土5。相克：金克木、木克土、土克水、水克火、火克金；相生：金生水、水生木、木生火、火生土、土生金。

- **倍率（全端统一）**：相克 **×1.25**、被克 **×0.8**、相生协同 **×1.15**、同元素 ×1.10。
- 团队：每相生对 +5%，五行齐全 +20%；共鸣：基础 10%伤/5%防，高级 20%/10%，混沌（五系齐全）35%/20%。
- 元素属性加成：金 暴击+5%物伤+15%；木 回血 2%；水 闪避+4%冰冻3%；火 灼烧10%/tick；土 防御+12%护盾8%。
- ⚠️ 遗留：服务端"被克"表保留历史映射（`CombatCalculator.cs:46-51` 注释自认"标准五行应为…"，如 火攻木×0.8、木攻水×0.8、土攻金×0.8 属非标准对），修改会动权威数值与金轨迹，留待专门的平衡性决策。

**技能**：`SkillDatabase` 每技能带 Element+DamageMultiplier+EnergyCost（裂金斩 ×1.5 耗30、万剑归宗 ×3.5 耗60、焚天灭地 ×4.0 耗80、磐石护体倍率 0 纯护盾）；升级倍率 `DamageMultiplier + DamagePerLevel×(level−1)`；类型：攻击/控制/位移/辅助/终结；EffectSystem 支持 Buff/Debuff/HoT/控制。

**轻功**：三段跳（段高系数 1.0/0.7/0.5，`base=min(2.0+(等级−1)×0.5, 5.0)`，起跳速 `√(2×9.81×h)`）；耗内力一段10/二段15/三段20/更多25；滑翔重力×0.3、耗体力 5/s、上限 10s；输入位 bit3/bit4 上报，服务端"轻功跳≤3"豁免。⚠️ 滑翔水平位移与动画调用被注释、QinggongLevel 无成长来源。

## 剩余缺口（截至 2026-09-26）

1. **等级/经验/升级成长**：服务端零实现（`MaxExp=1000+Level×500` 仅客户端展示曲线；GM 加经验被注释、升级事件仅日志）；无升级属性成长公式。
2. **DS 路径战斗属性**：`DsWorldSession.BuildPlayerStats` 仍用固定配置值（Element=0）——需网关控制面为每个玩家会话注入角色属性，属较大重构，未在本次范围。
3. MagicAttack/MagicDefense 不吃加点；五行防御缺火系（规格未给）；面板 struct `FromComponent` 误填 Level（展示占位）；客户端 `CharacterAttributeManager` 本地模拟仍硬编码基础属性。
4. 装备加成未进入服务端结算（CombatGrain 注释"只写加点相关列"，装备系统各自接入中）。
