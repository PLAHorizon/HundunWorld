## 存储拓扑

**所有 Orleans GrainStorage（Default/GameStore/PassportStore/WorldSqlStore/FlowerStore/AIStore/PubSubStore）当前均走 Redis**（`Horizon.Orleans.Silo/Program.cs:456-560`；原 SQL Server ADO.NET 配置整段注释保留为"Redis 故障备份方案"）；Reminders 也走 Redis。三层持久化策略：

1. Orleans GrainState → Redis（热缓存）；
2. 权威业务数据 → SQL Server（EF Core/Dapper 仓储，"Redis 只是热缓存，此表是权威层"）；
3. presence/幂等/会话/IM Outbox → Redis 原生 key（presence TTL 90s）。

位置双轨：Redis 永久位置存储（`ICharacterPositionStore`）+ GrainState 降级 + `CharacterPositionArchiveService` 归档（24h 落库）。Game 库表前缀 `Game_HunduShijie_*`；`GameEntityContext` 30+ DbSet。

## 账号与安全体系

- **IdentityServer4**（`Horizon.WebApi/Identity/Config.cs`）：仅 ROPC 授权，客户端 `api_client`，API `iHuaxiaX`，Token 7 天 + 滑动 refresh 5 天；账密校验转发 Orleans `IPassportGrain`。
- 注册/登录：`AccountController`（signin/register/refresh/signout/changepassword/批量造号）；`PassportImTokenStore` 管 IM token；小程序授权 Controller。
- WebAdmin（Blazor+AntDesign）：Game 模块 10 页（角色/聊天/引导/用户/公会/物品模板/服务器/技能模板/交易日志/仪表盘）+ Flower 模块 35 页。
- 其他：SecurePasswordHasher、SensitiveWordFilter、MQTT Topic ACL、ComplianceGrain（实名/防沉迷，骨架）。

## IM / 音视频通话

- 独立进程 `Horizon.IM.Gateway`（TouchSocket + Orleans Client）；业务在 `Horizon.IM.Core/Handlers/`（Chat/Group/Contact/Call/GatewayHandler）；LZ4Pickler 压缩。
- 文本/媒体：私聊/群聊/陌生人/系统/会话/联系人协议齐备；语音/视频消息 ≤10MB 走 `ImMediaController` 上传 → **完整**。
- 通话：**信令完整、媒体 P2P UDP 直连（魔数 HDCL，1200B 分片），不过服务器**；音频 WASAPI→16kHz PCM→抖动缓冲（NAudio）；视频 Media Foundation 优先、DirectShow 回退、JPEG 编码 → **局域网可用；无 NAT 穿透/TURN/SRTP，公网缺位**。

## AI Kernel 与 IoT 定位

Semantic Kernel（Azure OpenAI）服务花卉行情分析/种植建议/RAG 知识库/预警归因；MQTTnet 自建 Broker + 设备消息→Grain 桥接（Silo 内托管）。**均为业务线工具，非武侠玩法核心**。
