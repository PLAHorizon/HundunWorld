## 客户端预测

- 固定步长 `1/60s`（`LocalSimulationSystem.FixedDtSeconds`）。⚠️ 实现偏差：Flax 侧 `ECSUpdateDriver` 每渲染帧 Tick 且无 accumulator，即 tick 生成速率=渲染帧率、步长恒 1/60。
- 输入包 `InputPacket{ClientTick, InputBits, LookYaw/Pitch, MoveX/Y, CharacterId, PredictedEndX/Y/Z, MaxSpeed}`；发送队列软上限 256 DropOldest；未确认环形缓冲 64，`ClientTick − LastAcked > 5` 触发冗余重传，只重传最近 10 个（`RetransmitMaxCount=10`；文档"全部重传"已过时）。
- 输入历史环形缓冲容量 256（≈4.3s@60Hz）。

## 服务端模拟与快照

- `ZoneShardGrain` 60Hz Tick；**增量快照每 3 tick 广播（20Hz）**（60Hz 全速广播曾致 tick 堆积）；全量快照每 60 tick（1s）强制；静止实体 6 tick 心跳兜底。
- 增量字段阈值：Transform 0.01f、整数值差 ≥1；baseline 缺失自愈：`BaselineResyncRequestPacket`（Kind=16）→ 服务端下 tick 全量，客户端限流队列 16。
- Correction 不占快照节拍，以 `EventPacket(SyncEventKind.Correction)` 随 fanout 立即下发。

## 服务器权威移动校验（`Horizon.Game.Sim/MovementValidator.cs`）

| 规则 | 阈值 | 违规原因码 |
|---|---|---|
| 位置漂移基准 | 0.5m（动态：`base + maxSpeed×rtt` 上限 12m） | PredictionDrift |
| 硬性速度帽 | 200 m/s | SpeedHackSuspected |
| 自报速度启发式 | 水平位移 > maxSpeed×1.5（3D→水平，防合法下落/轻功误报） | SpeedHackSuspected |
| 跳跃次数 | 普通 ≤2、轻功 ≤3（冲量 5.5/4.5/3.5） | JumpCountExceeded |
| 加速度 | 50 m/s²（≈5G，带时间窗防静止误判） | AccelerationExceeded |
| 瞬移 | 水平 100m | TeleportDetected |

- 地面约束：未注入 `GroundHeightSampler` 时信任客户端 `PredictedEndZ`，三重防伪造护栏（|dz|≥10m 不信任、z==0 视为未设置、drift 兜底）。
- 校验失败→`CorrectionPacket{LastProcessedClientTick=批内最大 ClientTick}`，防"重放已确认输入→Correction 风暴"死循环。
- P-F12 输入间隙吸附：批首 tick 不连续时权威位置直接对齐 PredictedEnd 并跳过首输入。
- 装配：`ZoneShardGrain` 构造 `SimWorld(PositionEpsilon=0.5, HardSpeedCap=200, MaxSpeed=6, TickDt=1/60)`；服务端自带修正风暴监测（5 次/2s，告警冷却 10s）。

## 客户端和解（ReconciliationSystem）

- Ack 只清历史不重放（防双重应用）；Correction：drift>0.5m → 过期判定（`LastProcessedClientTick < _lastAcked` 跳过）→ 从权威位置重放未确认输入（dt=1/60，截断最近 12 帧=200ms，复用同一 `IMovementStepper` 含地面约束）→ `SmoothDamp3` 临界阻尼追平（15/s≈4 帧）。
- 修正风暴抑制：5 次/2s → 冷却 1s；可经 appsettings `SyncReconciliation` 外化注入。

## 快照插值（远程实体）

- 自适应插值延迟 `targetDelay = max(avgInterval + 2·jitter, rtt/2 + rttJitter)`，clamp **[100, 200]ms**（SYNC_OPERATIONS.md 写 400ms 上限已过时）；RTT EWMA α=0.125、抖动 β=0.25；固定回退 0.1s；延迟变化速率限幅 0.3/s。
- Mirror 式快照时间缓冲 16 帧；`renderTick = latestServerTick − ceil(delay×60)`。
- 三路策略：缓冲时间插值（blend 8/s≈125ms）/停止态温和收敛（0.01m）/移动态 Lerp+外推（上限 0.25s、宽限 0.1s、陈旧衰减 3/s；Idle 态 Dead Reckoning 最长 2s）。
- 传送三档：≤200m 普通 Lerp；200~500m 加速混合 200ms smoothstep；>500m 硬跳。
- 实体状态机 Initializing/Active(≤1s)/Idle(1~5s)/Stale(5~90s)/Offline；90s 超时清理。
- 接收缓冲：快照 1024、事件 512（DropOldest）；单帧最多消费 32 快照。

## AOI 与双通道

- AOI：Morton 键空间索引（`ZoneShardAoi.cs` + `MortonCodec.cs`），chunk 进出订阅；SQL 侧 chunk_state/diff_log 按 morton 8 分区（`scripts/sql/001_world_state.sql`）。
- **双通道并存**：Orleans 通道为默认主轨（P-F3 合并 RPC：ReceiveInput+SubmitInput+BuildAck 单次 Grain 调用，RTT 3→1）；**DS 灰度通道**（`DsWorldSession`/`DsDataPlaneHost`/`DsDownlinkIngress`）走确定性内核（含 `CombatCore` splitmix64 掷骰，支持金轨迹对拍）。已修复：晚加入收不到 Spawn（按会话补发）、RemovePlayer 不广播 Despawn（幽灵残留）、快照 Transform 漏换轴（3D 位置错乱）。

## 帧协议与安全

- 帧格式：6–8B 头（Length4+Kind1+Flags1，Kind 冗余写入支持 fast-path 路由）+ MemoryPack + LZ4（>256B）；4MB 解压上限防解压炸弹。
- 防护：移动校验六规则、攻速下限 500ms、输入去重、IP 连接频率限制、握手 FormulaVersion 校验（缺版本被拒）、角色指纹抢占（重复登录踢旧）、断线超时退回选角 + 按需重连。
