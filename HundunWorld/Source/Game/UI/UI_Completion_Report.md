## 🔧 主要修复内容

### 1. 核心问题修复

#### ✅ _currentScene字段赋值问题
**问题描述**: UIStateManager中的_currentScene字段在某些情况下赋值不正确
**修复方案**:
- 优化了UIStateManager的初始化逻辑
- 添加了ResetSceneState方法重置场景状态
- 修复了Actor销毁逻辑，使用DontDestroyOnLoad确保状态管理器持久性
- 完善了状态转换的事件触发机制

#### ✅ FlaxEditor播放模式状态清理
**问题描述**: 编辑器播放模式退出后UI状态没有正确清理
**修复方案**:
- 添加了编辑器状态监听机制（SubscribeEditorEvents）
- 实现了OnEditorStateChanged事件处理
- 在检测到编辑器状态变化时自动重置UI状态
- 添加了完善的事件订阅/取消订阅机制

#### ✅ 注册界面切换Bug
**问题描述**: 注册和登录界面无法正常相互切换
**修复方案**:
- 修复了UIStateManager中CanTransitionTo方法的逻辑
- 允许GameStart状态直接转换到RegisterScreen
- 优化了所有场景间的转换规则
- 添加了双向切换支持和状态回退功能
