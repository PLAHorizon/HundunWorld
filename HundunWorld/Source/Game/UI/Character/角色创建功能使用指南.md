# 角色创建功能使用指南

## 功能概述

集成的角色创建系统结合了基础信息输入和MetaHuman外观编辑器，为玩家提供完整的角色定制体验。

## 核心组件

### 1. IntegratedCharacterCreationUI
**位置**: `Game/UI/Character/IntegratedCharacterCreationUI.cs`

**功能**:
- 左侧面板：基础信息输入
  - 角色名称（带实时验证）
  - 性别选择（男/女）
  - 职业选择（剑客、刀客、枪客、弓手、法师、道士、刺客、医师）
  
- 右侧面板：MetaHuman外观编辑器
  - 皮肤编辑（颜色、粗糙度、次表面散射）
  - 眼睛编辑（虹膜颜色、瞳孔大小、湿度）
  - 发型编辑（发根/发梢颜色、粗糙度、各向异性）

- 底部按钮栏
  - 随机生成按钮：随机生成角色名和职业
  - 取消按钮：返回角色选择界面
  - 创建角色按钮：提交创建请求

### 2. CharacterCreationSceneController
**位置**: `Game/UI/Character/CharacterCreationSceneController.cs`

**功能**:
- 管理IntegratedCharacterCreationUI的生命周期
- 监听场景切换事件
- 处理角色创建成功/取消回调
- 与CharacterService交互

## 使用方法

### 在Flax Editor中设置

1. **创建角色创建场景**：
   - 打开Flax Editor
   - 创建新场景或使用现有场景
   - 场景命名为 `CharacterCreation`

2. **添加UI Canvas**：
   ```
   - 在场景中创建Empty Actor
   - 命名为 "CharacterCreationUI"
   - 添加 UICanvas Script
   ```

3. **添加控制器脚本**：
   ```
   - 选中 "CharacterCreationUI" Actor
   - 添加 CharacterCreationSceneController Script
   ```

4. **设置场景切换**：
   - 确保UIStateManager已正确配置
   - CharacterSelectionUI中"创建角色"按钮应调用：
     ```csharp
     UIStateManager.Instance.TransitionToScene(SceneType.CharacterCreation);
     ```

### 代码集成示例

```csharp
// 在CharacterSelectionUI中添加创建角色按钮
var createButton = new Button
{
    Text = "创建新角色",
    // ... 其他属性
};
createButton.Clicked += () =>
{
    UIStateManager.Instance.TransitionToScene(SceneType.CharacterCreation);
};
```

### 处理创建成功回调

角色创建成功后会自动：
1. 调用 `CharacterService.SelectCharacter(character)` 选中新角色
2. 切换到 `SceneType.CharacterSelection` 场景
3. 刷新角色列表

## 数据流

```
用户输入基础信息
    ↓
调整MetaHuman外观
    ↓
点击"创建角色"按钮
    ↓
验证输入 (角色名2-12字符)
    ↓
显示加载指示器
    ↓
调用 CharacterService.CreateCharacterAsync()
    ↓
发送网络请求 CreateCharacterRequest
    ↓
等待服务器响应 CreateCharacterResponse
    ↓
【成功】
    ├─ 触发 OnCharacterCreated 事件
    ├─ 选中新创建的角色
    └─ 切换回角色选择场景
【失败】
    └─ 显示错误消息
```

## 验证规则

### 角色名称
- **最小长度**: 2个字符
- **最大长度**: 12个字符
- **不能为空**: 必须输入名称
- **实时验证**: 输入时即时显示验证结果

## 故障排除

### 问题1: UI不显示
**检查**:
- UICanvas是否正确添加到场景
- CharacterCreationSceneController是否附加到正确的Actor
- 场景类型是否匹配 (SceneType.CharacterCreation)

**解决**:
```csharp
// 在CharacterCreationSceneController.OnStart()中添加日志
Debug.Log($"UICanvas found: {uiCanvas != null}");
Debug.Log($"GUI found: {uiCanvas?.GUI != null}");
```

### 问题2: MetaHuman编辑器无法交互
**检查**:
- MetaHumanEditorUI是否正确初始化
- AppearanceEditor和PreviewController是否设置

**解决**:
```csharp
// 确保MetaHumanEditorUI的依赖项已正确创建
if (_metaHumanEditor.AppearanceEditor == null)
{
    Debug.LogWarning("AppearanceEditor未初始化");
}
```

### 问题3: 创建按钮一直禁用
**检查**:
- ValidatedTextBox的验证逻辑
- UpdateCreateButtonState()是否被调用

**解决**:
```csharp
// 添加调试日志
private void UpdateCreateButtonState()
{
    bool isValid = _nameInput.IsValid && 
                  !string.IsNullOrWhiteSpace(_nameInput.Text);
    
    Debug.Log($"Name valid: {_nameInput.IsValid}, Text: {_nameInput.Text}");
    _createButton.Enabled = isValid;
}
```
