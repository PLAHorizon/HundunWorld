# 角色创建中心布局使用指南

## 布局概述

新的角色创建界面采用**中心化环形布局**设计，让3D角色模型在屏幕中央得到充分展示，四周环绕着必要的操作面板。

## 布局结构

### 1. 中央3D预览区域
- **位置**: 屏幕中心
- **功能**: 实时显示角色3D模型
- **特点**: 
  - 使用深色背景突出3D效果
  - 集成完整的MetaHuman外观编辑器
  - 支持模型旋转、动画播放等交互

### 2. 顶部控制面板
- **位置**: 屏幕顶部
- **包含元素**:
  - 标题："角色创建中心"
  - 随机生成按钮
  - 取消按钮
- **功能**: 提供全局控制选项

### 3. 左侧信息面板
- **位置**: 屏幕左侧
- **功能**: 基础信息输入
- **包含内容**:
  - 角色名称输入（带实时验证）
  - 性别选择（男/女）
  - 职业选择（8种职业）
  - 状态提示信息

### 4. 右侧编辑面板
- **位置**: 屏幕右侧
- **功能**: 外观编辑辅助
- **包含内容**:
  - 外观编辑提示
  - 快捷操作按钮
  - 编辑状态说明

### 5. 底部按钮面板
- **位置**: 屏幕底部居中
- **功能**: 主要操作按钮
- **包含按钮**:
  - 创建角色（主按钮，高亮显示）
  - 取消创建

## 布局优势

### 1. 视觉焦点明确
- 3D角色模型位于中央，成为视觉焦点
- 四周UI元素不干扰中央显示
- 用户注意力自然集中到角色预览上

### 2. 操作流程优化
- 基础信息在左侧，符合阅读习惯
- 外观编辑在中央，直观易操作
- 主要按钮在底部，便于确认操作

### 3. 空间利用高效
- 环形布局最大化中央显示区域
- 四周面板宽度适中，不显拥挤
- 响应式设计适配不同屏幕尺寸

### 4. 界面美观现代
- 半透明背景营造层次感
- 统一的色彩搭配和样式
- 圆角设计提升视觉品质

## 使用流程

### 1. 基础信息填写
- 在左侧面板填写角色名称
- 选择性别和职业
- 状态标签会实时显示填写进度

### 2. 外观定制
- 在中央区域操作MetaHuman编辑器
- 调整皮肤、眼睛、毛发等参数
- 实时预览外观效果

### 3. 快捷操作
- 使用顶部随机生成按钮快速创建角色
- 右侧面板提供重置等快捷功能
- 底部按钮完成创建或取消操作

## 技术实现要点

### 帆布布局
```csharp
// 使用锚点系统实现响应式布局
AnchorPreset = AnchorPresets.MiddleCenter;
Offsets = new Margin(200, 200, 200, 120); // 为四周留出空间
```

### 层级管理
```csharp
// 确保按钮面板在最上层
_buttonPanel.IndexInParent = 100;
```

### 背景设计
```csharp
// 半透明背景增强层次感
BackgroundColor = new Color(0.05f, 0.05f, 0.07f, 0.95f);
```

## 响应式适配

### 大屏幕（>1920px）
- 保持标准布局
- 增加面板间距
- 提升字体大小

### 中等屏幕（1366px-1920px）
- 使用标准尺寸
- 保持所有功能完整

### 小屏幕（<1366px）
- 适当压缩面板宽度
- 调整字体和按钮大小
- 保持核心功能可用

## 用户体验优化

### 1. 视觉引导
- 中央3D区域自动吸引注意力
- 颜色对比突出重要元素
- 动画效果增强交互反馈

### 2. 操作便利性

- 按钮大小适中，易于点击

## 注意事项

### 性能考虑
- 中央3D渲染需要较高性能
- 建议在中高端设备上使用
- 可根据设备性能调整渲染质量

### 兼容性
- 确保在不同分辨率下正常显示
- 测试各种屏幕比例的适配效果
- 验证触控设备的操作体验

### 可访问性
- 提供键盘操作支持
- 确保颜色对比度符合标准
- 考虑色盲用户的需求

这个新的环形布局设计让角色创建体验更加直观和高效，3D角色预览成为界面的核心，用户可以专注于角色外观的定制和预览。
