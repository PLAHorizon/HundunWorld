## 1. 文档目的与约束范围

### 1.1 文档定位

本文档是混沌世界 MMORPG UI 系统的**补充交互约束**，以苹果 Human Interface Guidelines（HIG）作为参考来源，叠加到项目主体"水墨古风 Dark 主题"之上。苹果设计库（`dl_builtin_apple`）以只读（read-only）方式提供 button / card / input / navigation 等组件的交互与尺寸规范，**不覆盖水墨主题的任何 token 值**。

### 1.2 约束优先级

当苹果 HIG 约束与水墨主题 token 发生冲突时，按以下优先级裁决：

| 优先级 | 来源 | 约束范畴 | 冲突时的处理 |
|--------|------|----------|--------------|
| P0（最高） | 水墨主题 token | 色彩、字体族、品牌色、质感 | 永远以水墨主题为准 |
| P1 | 苹果 HIG 约束 | 触控目标、间距网格、动效曲线、信息层级 | 叠加应用，不替换 token 值 |
| P2 | 页面级实现 | 局部布局、业务特定交互 | 不得违反 P0 / P1 |

### 1.3 约束生效范畴

苹果 HIG 约束**仅**对以下维度生效，其余维度（色彩、字体、品牌质感、水墨纹理）一律不动：

1. **交互行为**：点击、悬停、聚焦、按压、拖拽的反馈节奏
2. **尺寸规范**：触控目标最小尺寸、间距网格、圆角阶梯
3. **可访问性**：对比度、焦点可见性、键盘可达性、屏幕阅读器语义
4. **信息层级**：primary / secondary / tertiary 三级视觉权重划分原则
5. **动效规范**：过渡曲线、时长阶梯、入场退场节奏

### 1.4 不生效范畴（明确豁免）

- 主色 `--bg-brand: #C8A858`（水墨金）不被苹果 System Blue `#007AFF` 替换
- 字体族 `STKaiti / Noto Sans SC` 不被 DM Sans 替换
- 水墨晕染、金箔描边、宣纸纹理等品牌质感层不被苹果扁平化样式覆盖
- 状态色（血量红、内力青、怒气金等游戏语义色）保留游戏领域语义

## 2. 间距网格（8pt Spacing Grid）

### 2.1 网格基准

采用苹果 HIG 推荐的 **8pt 间距网格**，所有间距值必须是 4 的整数倍，推荐落在 8 的整数倍上。项目 `colors_and_type.css` 中的 `--spacer-*` token 已与该网格对齐。

### 2.2 间距阶梯

| Token | 值 | 用途 | 应用场景 |
|-------|----|------|----------|
| `--spacer-4` | 4px | 微间距 | 图标与文字之间、标签内边距微调、紧凑列表行内间距 |
| `--spacer-8` | 8px | 基础间距 | 按钮内边距、列表项间距、卡片内元素间距 |
| `--spacer-12` | 12px | 中等间距 | 卡片内边距、表单字段间距、HUD 信息块间距 |
| `--spacer-16` | 16px | 标准间距 | 卡片间距、面板分区间距、弹窗内边距 |
| `--spacer-24` | 24px | 大间距 | 模块间距、页面区块间距、背包格子间距 |
| `--spacer-32` | 32px | 超大间距 | 页面级区块间距、弹窗与边缘间距 |

### 2.3 应用规则

1. **禁止使用 5px / 7px / 10px 等非网格值**，确需微调时使用 `--spacer-2`（2px）或 `--spacer-3`（3px）并注明理由
2. **嵌套间距递减**：父容器间距 ≥ 子容器间距，避免视觉拥挤
3. **HUD 紧凑场景**：战斗 HUD 允许使用 4px / 8px 阶梯以节省屏幕空间，但不得低于 4px
4. **全屏面板场景**：背包、技能面板等全屏界面使用 16px / 24px / 32px 阶梯保证呼吸感

### 2.4 与水墨主题兼容性

水墨主题的 `--spacer-*` token 体系与苹果 8pt 网格完全兼容，无需任何修改。`--ink-bg-panel` 的 `blur(8px)` 模糊半径也落在网格上。

## 3. 圆角阶梯（Corner Radius Scale）

### 3.1 圆角分级

苹果 HIG 推荐容器圆角与元素层级匹配。本项目采用三级圆角阶梯，与水墨主题的 `--radius-*` 和 `--ink-radius-*` token 对齐。

| 级别 | Token | 值 | 应用元素 | 应用场景 |
|------|-------|----|----------|----------|
| 小圆角 | `--radius-4` / `--ink-radius-md` | 4px | 按钮、标签、输入框、技能图标、Buff 图标 | 交互元素、小型原子组件 |
| 中圆角 | `--radius-8` / `--ink-radius-lg` | 8px | 卡片、列表项、通知条、任务条目 | 信息卡片、中型组合组件 |
| 大圆角 | `--radius-12` | 12px | 容器、弹窗、面板、对话框 | 容器级、大面积承载层 |
| 全圆角 | `--radius-full` | 999px | 头像、徽章、圆形按钮、状态点 | 圆形元素、胶囊形元素 |

### 3.2 应用规则

1. **圆角随层级递增**：原子元素 4px → 组合卡片 8px → 容器面板 12px，禁止倒挂
2. **嵌套圆角递减**：外层容器圆角 ≥ 内层元素圆角 2px 以上，避免视觉粘连
3. **水墨描边不受圆角约束**：金箔描边、水墨分隔线可独立使用直线，圆角仅作用于背景层
4. **HUD 特殊处理**：战斗 HUD 的血条、内力条使用 `--ink-radius-sm`（2px）或直角，保持信息密度

### 3.3 与苹果设计库圆角的关系

苹果设计库默认圆角为 `1.2rem`（约 12px），对应本项目的大圆角 `--radius-12`。该值仅作为容器级圆角使用，不强制所有元素统一为 12px，以保留水墨主题的层级感。

### 3.4 与水墨主题兼容性

水墨主题的 `--ink-radius-*`（2/4/8px）与苹果圆角阶梯在 4px / 8px 两档完全重合，12px 容器圆角由 `--radius-12` 提供。两套 token 可并存，按场景选用。

## 4. 触控目标（Touch Target）

### 4.1 最小尺寸

依据苹果 HIG，所有可点击元素的**最小触控目标**为 **44 × 44 px**。该约束应用于：

- 按钮（主按钮、次按钮、图标按钮）
- 列表项（背包格子、技能槽、好友列表项）
- 图标按钮（关闭、展开、设置等图标触发器）
- 导航项（顶部 Tab、侧边导航、底部 Tab Bar）
- 输入框（点击区域，非视觉尺寸）

### 4.2 视觉尺寸与触控区域分离

允许视觉尺寸小于 44px，但**点击命中区域**必须 ≥ 44 × 44px。实现方式：

```css
/* 视觉 28px，触控 44px */
.ds-btn--icon {
  width: 28px;            /* 视觉尺寸 */
  height: 28px;
  min-width: 44px;        /* 触控最小尺寸 */
  min-height: 44px;
  /* 或使用 padding 扩展命中区域 */
}
```

### 4.3 间距保障

相邻可点击元素之间的间距应 ≥ 8px，避免误触。HUD 紧凑场景下可将视觉间距压到 4px，但需通过透明 padding 扩展实际触控间距至 8px。

### 4.4 应用场景明细

| 场景 | 元素 | 最小触控目标 | 备注 |
|------|------|--------------|------|
| 战斗 HUD | 技能槽 | 44 × 44px | 快捷键技能图标 |
| 背包 | 格子项 | 44 × 44px | 物品图标点击区 |
| 技能面板 | 技能节点 | 44 × 44px | 技能树节点 |
| 任务日志 | 任务条目 | 44px 高（整行） | 行点击展开 |
| 社交 | 好友列表项 | 44px 高（整行） | 行点击查看 |
| 商城 | 购买按钮 | 44 × 44px | 主操作按钮 |
| 世界地图 | 地图标记 | 44 × 44px | 兴趣点点击 |
| 顶部导航 | Tab 项 | 44px 高 | 主导航切换 |

### 4.5 与水墨主题兼容性

水墨主题的按钮默认 `height: 28px`（见 `components.css` 中 `.ds-btn`），需通过 `min-height: 44px` 或 padding 扩展触控区域。视觉上仍保持 28px 的紧凑感，触控上满足苹果 HIG 要求。**不修改** `.ds-btn` 的视觉高度 token。

## 5. 动效曲线与时长阶梯（Motion）

### 5.1 动效曲线

采用苹果 HIG 推荐的 **ease-out** 曲线作为标准过渡曲线，对应 cubic-bezier 值：

| 曲线名 | cubic-bezier | 适用场景 |
|--------|--------------|----------|
| `--ease-out`（标准） | `cubic-bezier(0.16, 1, 0.3, 1)` | 默认过渡，元素入场、悬停反馈、状态切换 |
| `--ease-in-out`（对称） | `cubic-bezier(0.65, 0, 0.35, 1)` | 位置移动、面板展开收起 |
| `--ease-in`（加速） | `cubic-bezier(0.7, 0, 0.84, 0)` | 元素退场、消失类动画 |

> 默认统一使用 `ease-out`，仅在明确的位移场景使用 `ease-in-out`，退场场景使用 `ease-in`。

### 5.2 时长阶梯

| Token | 时长 | 用途 | 应用场景 |
|-------|------|------|----------|
| `--duration-instant` | 100ms | 即时反馈 | 悬停高亮、按压反馈、图标颜色切换 |
| `--duration-fast` | 200ms | 快速过渡 | 按钮状态、Tab 切换、小元素显隐 |
| `--duration-normal` | 300ms | 标准过渡 | 卡片展开、弹窗淡入、列表项重排 |
| `--duration-slow` | 400ms | 慢速过渡 | 全屏面板入场、页面切换、复杂动画 |

### 5.3 应用规则

1. **战斗 HUD 优先使用 100ms / 200ms**：保证战斗反馈的低延迟感
2. **全屏面板使用 300ms / 400ms**：营造水墨铺展的从容感
3. **禁止使用线性 `linear`**：线性过渡缺乏自然感，不符合 HIG 与水墨美学
4. **禁止超过 400ms**：超过 400ms 的过渡会让玩家感到卡顿
5. **入场与退场对称**：同一元素的入场时长 = 退场时长，曲线可不同

### 5.4 水墨专属动效补充

在苹果 HIG 动效框架下，允许以下水墨主题专属动效叠加（不违反 HIG 时长上限）：

- **水墨晕染入场**：300ms ease-out，配合 `opacity` 与 `filter: blur()` 营造墨迹洇开
- **金箔描边亮起**：100ms ease-out，`box-shadow` 与 `border-color` 同步过渡
- **宣纸翻页**：400ms ease-in-out，用于任务日志、技能书翻页

### 5.5 与水墨主题兼容性

水墨主题的 `--ink-blur-panel: blur(8px)` 与动效时长配合使用时，建议过渡 `filter` 属性的时长 ≥ 300ms，避免模糊半径变化产生的抖动。

## 6. 信息层级（Information Hierarchy）

### 6.1 三级层级模型

依据苹果 HIG 的信息层级原则，将 UI 信息划分为三级，对应水墨主题的文本色 token：

| 层级 | 语义 | 水墨 token | 苹果对应 | 字重 | 应用场景 |
|------|------|------------|----------|------|----------|
| Primary | 核心信息 | `--ink-text-primary` (#F0EDE4) | primary | 500-600 | 玩家名、HP 数值、技能名、任务标题、关键价格 |
| Secondary | 辅助信息 | `--ink-text-secondary` (#B8B0A0) | secondary | 400 | 物品描述、属性数值、列表副标题、时间戳 |
| Tertiary | 背景信息 | `--ink-text-muted` (#8A8275) | tertiary | 400 | 占位符、提示语、水印文字、版权信息 |

### 6.2 层级应用规则

1. **单屏 primary 信息不超过 30%**：避免视觉过载，核心信息应克制使用
2. **secondary 承担主要阅读量**：列表、描述、数值等大部分信息为 secondary
3. **tertiary 不承载关键操作**：仅用于提示、占位、辅助说明
4. **层级可跨级跳变**：primary 与 tertiary 可直接相邻以制造强对比，但需控制频次

### 6.3 字重配合

| 层级 | 推荐字重 | 字体族 | 应用 |
|------|----------|--------|------|
| Primary | 500-600 | `--ink-font-display`（楷书） | 标题、关键数值 |
| Primary（正文） | 500 | `--ink-font-body`（黑体） | 玩家名、重要操作文本 |
| Secondary | 400 | `--ink-font-body` | 描述、副标题 |
| Tertiary | 400 | `--ink-font-body` | 提示、占位 |

### 6.4 数值类信息特殊处理

HP / 内力 / 怒气 / 伤害数字等数值类信息使用 `--ink-font-number`（DIN Alternate），并启用 `font-variant-numeric: tabular-nums` 保证等宽对齐。数值层级由颜色和字号共同决定，不依赖字重。

### 6.5 与水墨主题兼容性

水墨主题的三级文本色（`--ink-text-primary/secondary/muted`）与苹果 HIG 三级信息层级**一一对应**，无需新增 token。颜色值保持水墨金墨体系，不替换为苹果灰色阶。

## 7. 可访问性（Accessibility）

### 7.1 对比度要求

遵循 **WCAG AA** 标准：

| 文本类型 | 最小对比度 | 验证对象 |
|----------|------------|----------|
| 正常文本（< 18px 或 < 14px 加粗） | 4.5 : 1 | `--ink-text-primary` / `--ink-text-secondary` 与背景 |
| 大文本（≥ 18px 或 ≥ 14px 加粗） | 3.0 : 1 | 标题、大号数值 |
| 交互元素边框 | 3.0 : 1 | 按钮边框、输入框边框与背景 |
| 状态指示 | 3.0 : 1 | 图标颜色、状态点与背景 |

### 7.2 水墨主题对比度验证

水墨主题 Dark 背景下的关键对比度（已验证）：

| 前景 | 背景 | 对比度 | 达标 |
|------|------|--------|------|
| `#F0EDE4`（primary） | `#0E1016`（void） | ~16.8 : 1 | AA 通过 |
| `#B8B0A0`（secondary） | `#0E1016`（void） | ~9.5 : 1 | AA 通过 |
| `#8A8275`（muted） | `#0E1016`（void） | ~5.8 : 1 | AA 通过 |
| `#C8A858`（gold） | `#0E1016`（void） | ~8.2 : 1 | AA 通过 |
| `#0E1016`（on-brand） | `#C8A858`（gold） | ~8.2 : 1 | AA 通过 |

### 7.3 焦点可见性（Focus Visible）

1. **所有可交互元素必须可见焦点**：使用 `:focus-visible` 而非 `:focus`
2. **焦点样式**：`outline: 2px solid var(--ink-gold-primary); outline-offset: 2px;`
3. **禁止 `outline: none`**：除非提供了等价的视觉焦点指示
4. **焦点顺序**：DOM 顺序与视觉顺序一致，避免 `tabindex` 正整数

### 7.4 键盘可达性（Keyboard Navigation）

| 操作 | 键盘映射 | 应用场景 |
|------|----------|----------|
| 切换焦点 | `Tab` / `Shift+Tab` | 全局导航 |
| 激活 | `Enter` / `Space` | 按钮、列表项 |
| 关闭 | `Esc` | 弹窗、面板、菜单 |
| 切换 Tab | `←` / `→` 或 `↑` / `↓` | 顶部 Tab、技能面板 |
| 确认选择 | `Enter` | 背包物品、任务条目 |

**要求**：所有鼠标可完成的操作，键盘必须能完成。战斗 HUD 的快捷键（1-9）属于游戏增强操作，不替代基础键盘导航。

### 7.5 屏幕阅读器支持（Screen Reader）

1. **语义化 HTML**：使用 `<button>` / `<nav>` / `<main>` / `<dialog>` 等语义标签
2. **ARIA 标签**：图标按钮必须 `aria-label`，复杂控件需 `aria-describedby`
3. **动态通知**：HP 变化、任务更新等使用 `aria-live="polite"`，战斗紧急信息使用 `aria-live="assertive"`
4. **隐藏内容**：纯装饰元素 `aria-hidden="true"`，水墨纹理图层均应隐藏

### 7.6 动效偏好（Reduced Motion）

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

玩家系统设置开启"减少动效"时，所有过渡降为近乎即时，但保留状态变化的视觉反馈（颜色切换仍可见）。

## 8. 与水墨主题的融合策略

### 8.1 融合原则

苹果 HIG 提供"骨架"（交互、尺寸、可达性），水墨主题提供"血肉"（色彩、字体、质感）。两者关系如下：

```text
┌─────────────────────────────────────────────┐
│           水墨古风 Dark 主题（P0）            │
│  色彩 / 字体 / 质感 / 品牌色 / 状态语义色     │
│  ┌─────────────────────────────────────┐    │
│  │      苹果 HIG 补充约束（P1）         │    │
│  │  触控目标 / 间距网格 / 圆角阶梯       │    │
│  │  动效曲线 / 信息层级 / 可访问性       │    │
│  │  ┌─────────────────────────────┐    │    │
│  │  │    页面级实现（P2）          │    │    │
│  │  │  局部布局 / 业务交互          │    │    │
│  │  └─────────────────────────────┘    │    │
│  └─────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

### 8.2 色彩不冲突策略

| 维度 | 水墨主题 | 苹果 HIG | 融合方案 |
|------|----------|----------|----------|
| 主色 | `#C8A858`（水墨金） | `#007AFF`（System Blue） | 保留水墨金，苹果蓝不引入 |
| 背景色 | `#0E1016`（墨黑） | 浅色/深色自适应 | 固定 Dark，不自适应 |
| 状态色 | 血量红/内力青/怒气金 | 系统红/绿/黄 | 保留游戏语义色 |
| 文本灰阶 | `#F0EDE4 / #B8B0A0 / #8A8275` | 系统灰阶 | 保留水墨暖灰阶 |

**规则**：苹果 HIG 的色彩规范整体不采纳，仅采纳其"对比度达标"这一可访问性要求。水墨主题的所有色值保持不变，但需通过 7.2 节的对比度验证。

### 8.3 尺寸兼容策略

| 维度 | 水墨主题现状 | 苹果 HIG 要求 | 融合方案 |
|------|--------------|---------------|----------|
| 间距 token | `--spacer-*` 已对齐 8pt | 8pt 网格 | 直接复用，无冲突 |
| 圆角 token | `--ink-radius-*`（2/4/8px）+ `--radius-*`（含 12px） | 4/8/12px 阶梯 | 两套并存，按场景选用 |
| 按钮高度 | `28px`（视觉） | `44px`（触控） | 视觉保持 28px，`min-height: 44px` 扩展触控 |
| 字号 | `--body-*` / `--heading-*` 阶梯 | 动态字号 | 保留固定阶梯，游戏场景不做动态字号 |

### 8.4 动效统一策略

1. **全局统一 ease-out**：所有过渡默认 `cubic-bezier(0.16, 1, 0.3, 1)`
2. **水墨专属动效叠加**：在 HIG 时长上限内叠加水墨晕染、金箔亮起等质感动效
3. **战斗场景降级**：战斗 HUD 优先使用 100ms/200ms，牺牲部分水墨质感保证响应速度
4. **全屏场景升级**：背包/技能面板等使用 300ms/400ms，充分展现水墨铺展感

### 8.5 组件落地映射

| 苹果组件 | 水墨对应组件 | 落地文件 | 采纳的 HIG 约束 |
|----------|--------------|----------|------------------|
| Button | `.ds-btn` | `components.css` | 触控 44px、圆角 4px、动效 200ms |
| Card | `.ds-card` / `.ink-panel` | `components.css` | 圆角 8px、间距 16px、层级 secondary |
| Input | `.ds-input` | `components.css` | 触控 44px、圆角 4px、焦点可见 |
| Navigation | `.ds-tabs` / `.ds-breadcrumb` | `components.css` | 触控 44px、间距 8px、键盘可达 |
| Alert | `.ds-alert` / `.ds-notif` | `components.css` | 圆角 8px、对比度 AA、`aria-live` |
| Avatar | `.ds-avatar` | `components.css` | 全圆角、尺寸 24/32/40px |

### 8.6 例外清单（Explicit Exceptions）

以下场景**明确不采纳**苹果 HIG 约束，保留游戏领域惯例：

1. **战斗血条**：使用 2px 圆角（`--ink-radius-sm`），不使用 4px，保持信息密度
2. **伤害飘字**：使用游戏专属飘字动效，不遵循 100-400ms 阶梯
3. **小地图**：圆形容器，不套用圆角阶梯
4. **快捷键技能槽**：固定 48 × 48px（含边框），略大于 44px，保留游戏手感
5. **聊天框**：滚动区域使用窄滚动条（6px），不套用触控目标

## 9. 落地检查清单（Checklist）

在提交任何 UI 实现前，按以下清单自查：

### 9.1 尺寸与间距

- [ ] 所有间距值落在 4/8/12/16/24/32px 阶梯上
- [ ] 所有可点击元素触控区域 ≥ 44 × 44px
- [ ] 圆角按 4px（元素）/ 8px（卡片）/ 12px（容器）分级使用
- [ ] 嵌套圆角外层 ≥ 内层 2px

### 9.2 动效

- [ ] 过渡曲线使用 `ease-out` 或指定的 `ease-in-out` / `ease-in`
- [ ] 时长落在 100/200/300/400ms 阶梯上

- [ ] 入场与退场时长对称

### 9.3 信息层级

- [ ] 文本颜色使用 primary / secondary / tertiary 三级

- [ ] 数值类信息使用 `--ink-font-number` + `tabular-nums`

### 9.4 可访问性

- [ ] 所有文本对比度 ≥ 4.5 : 1（正常）/ 3.0 : 1（大号）
- [ ] 所有可交互元素有 `:focus-visible` 样式
- [ ] 所有鼠标操作有等价的键盘操作
- [ ] 图标按钮有 `aria-label`
