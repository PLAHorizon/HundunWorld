0 · 申办流程总览

前置说明

  • 需要一台已实名认证的手机微信 + 一个可用的手机号。
  • App 支付要求注册主体为企业或个体工商户；个人主体无法开通。
  • 全流程共 3 个阶段、6 个步骤；第 3 步（开通 App 支付产品）是唯一硬性门槛，标金高亮。
阶段一 · 微信开放平台

1 · 注册微信开放平台账号（可跳过）

目的：获得一个已认证的开放平台账号，作为后续创建应用与绑定商户号的前提。
  • 访问 open.weixin.qq.com，点击右上角「登录」。
  • 用企业/个体主体的微信扫码登录，按提示完成开发者资质认证（认证费约 300 元/年，企业主体）。
  • 个人主体只能注册「个人开发者」，不开放 App 支付。
⚠️ 尚未认证的话，这是后续所有步骤的前置门槛，请优先完成。
阶段一 · 微信开放平台

2 · 创建「移动应用」并获取 AppID

  1. 登录开放平台 → 管理中心 → 移动应用 → 创建移动应用。
  2. 如实填写名称、简介、图标；平台类型选 HarmonyOS / OpenHarmony（无此选项则选「Android」并在备注注明鸿蒙）。
  3. 提交审核，通过后在应用信息页拿到 AppID（形如 wx8c0e...）。
  4. 记录该 AppID —— 后续服务端 WECHAT_APP_ID 与客户端 scheme 都使用它。
客户端 module.json5 的微信回调 scheme 需填 wx + 该 AppID（见第 6 步）。
阶段二 · 微信支付商户平台

3 · 注册支付商户号（开通 App 支付）

  1. 访问 pay.weixin.qq.com，点击「接入微信支付」→ 选择 App 支付，用已认证的开放平台账号关联登录。
  2. 提交营业执照、法人/经营者身份、银行结算账户等资料，等待审核（1~3 个工作日）。
  3. 通过后，在「账户中心 → 商户信息」拿到 商户号（mchid），形如 1900001xxx。
  4. 完成超级管理员/操作员角色绑定，方便后续获取密钥。
申请时务必勾选产品类型 App 支付；漏选则需后续在「产品中心 → App支付」手动开通。
阶段二 · 微信支付商户平台

4 · 开通 API v3，获取证书与密钥

全程需商户超级管理员配合扫码授权，产出三样关键凭据。

4.1 获取 APIv3 密钥

账户中心 → API安全 → 设置APIv3密钥，设置一个 32 位密钥并妥善保存 → 对应 WECHAT_V3_SECRET。

4.2 获取 API 证书（双向 TLS）

账户中心 → API安全 → 申请API证书，按向导下载「微信支付证书工具」，导出商户 API 证书，得到：

  • 商户证书序列号 → WECHAT_CERT_SERIAL
  • 商户私钥（apiclient_key.pem） → WECHAT_PRIVATE_KEY
未申请 API 证书时，服务端无法完成 v3 签名，下单会报「商户配置缺失/签名失败」。务必完成这一步。
阶段三 · 关联与接入

5 · 开放平台绑定商户号并关联应用

  1. 回到微信开放平台 → 你的移动应用 → 支付能力 / 关联 AppID 与商户号。
  2. 将第 3 步的商户号与第 2 步的AppID进行绑定。
  3. 确认绑定成功后，App v3 下单才能通过校验。
阶段三 · 关联与接入

6 · 把凭据配置到本项目

以下六项凭据，二选一方式填入（推荐环境变量，避免明文进仓库）：

配置项来源说明
WECHAT_MERCHANT_ID第 3 步商户号 mchid
WECHAT_APP_ID第 2 步开放平台移动应用 AppID
WECHAT_V3_SECRET4.1APIv3 32 位密钥
WECHAT_CERT_SERIAL4.2商户证书序列号
WECHAT_PRIVATE_KEY4.2商户私钥（PEM，含头尾）
WECHAT_NOTIFY_URL自行提供公网 HTTPS 回调地址

方式 A：环境变量（推荐）

$env:WECHAT_MERCHANT_ID="1900001xxx"
$env:WECHAT_APP_ID="wx8c0e..."
$env:WECHAT_V3_SECRET="32位密钥"
$env:WECHAT_CERT_SERIAL="证书序列号"
$env:WECHAT_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...-----END PRIVATE KEY-----"
$env:WECHAT_NOTIFY_URL="https://你的域名/FlowerPayment/callback/wechat"

方式 B：appsettings.json

"WechatPaySettings": {
  "MerchantId": "1900001xxx",
  "AppId": "wx8c0e...",
  "MerchantV3Secret": "32位密钥",
  "CertSerialNumber": "证书序列号",
  "PrivateKey": "-----BEGIN PRIVATE KEY-----...",
  "NotifyUrl": "https://你的域名/FlowerPayment/callback/wechat",
  "IsSandbox": false
}

客户端同步修改

  1. PaymentService.ets 内 MOCK_PAYMENT_ENABLED 改为 false。
  2. module.json5 的 scheme wxAPPID 改为 wx + 你的 AppID（小写）。

7 · 真机验证

  1. 重启 Silo，确认日志无「商户配置缺失」报错。
  2. 打包鸿蒙客户端并安装到真机。
  3. 下单 → 选微信支付 → 应能拉起微信收银台并完成支付。
  4. 支付后服务端收到回调并更新订单为「已支付」。

常见问题排查

现象原因处理
问题 无法创建移动应用 未完成开发者资质认证 处理 完成企业 / 个体开发者认证
问题 App 支付申请被拒 注册主体为个人 处理 升级为企业 / 个体户主体
问题 下单报「签名失败」 APIv3 密钥或证书不正确 处理 核对 APIv3 密钥与证书序列号 / 私钥
问题 拉起不了收银台 IsSandbox 设为 true（沙箱不支持 App） 处理 改为 false，走正式环境
问题 微信回调不到 scheme 未配置或 NotifyUrl 无公网访问 处理 配置 scheme + 公网 HTTPS 回调地址
